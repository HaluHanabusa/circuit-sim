# E1g: エンジンとアプリの口（番号つきの注意とエラー、進み具合と中断、信号の単位）

担当: solver-engineer ／ 依存: E1b ／ 次: A1（実行画面）

## 目的

画面仕様（`docs/design/screens-v0.1.md` 12章、14章の未決5・6・8）が求める形で、エンジンが結果を返せるようにする。

## 範囲

1. **注意とエラーを番号と差し込む値で返す**: 今は日本語の文がそのまま返る。番号（例: `STEP_COARSE`）と差し込む値（数値は単位つき）の組で返し、日本語と英語の文面は辞書から作る。いまの日本語の文面は辞書の日本語として残す。コマンドラインはその辞書で表示する。番号と画面仕様の付録B（お知らせの一覧）の対応表を作る。
2. **進み具合と中断**: 計算を区切って進め、進み具合（0〜1）を知らせる口と、中断の口を持つ。中断したら途中の結果を返さず、中断したと分かる形で終わる。核の最内ループの決まりを守る（区切りは核の外で）。進み具合を知らせる間隔と、区切ることによる遅れ（区切らない場合との所要時間の差）を測る。
3. **信号の単位と説明**: 結果の信号ごとに、単位（V、A、無次元）と向きの説明（電流の正の向き）を返す。
4. **CSV の見出しに単位**（未決8）: コマンドラインの `--csv` の見出しを、画面と同じ形（例: `v(out) [V]`）にする。
5. **指令で値が決まる電源の変わり目の記録**（E1b のレビューの軽3）: 制御時刻に指令の値が変わると、いまは測定・記録される代数的な変数（電源の電流など）が「変わった後」の値になる。`control/interface.py` の説明（切り替えの直前の値）と、スイッチの切り替え点の扱い（D-019: 切り替え前の値を記録）に合わせ、変わり目では直前の値を記録する。積分の精度（2次）は保つ。
6. **テンプレートの注意を結果に入れる**（E1b の検証の軽3）: テンプレートの展開で出た注意（`Expanded.notes`。例: C_esr を省いたとき）が、いまは `Result.notes` と CSV に入らない。1 の番号つきの形で結果に入れ、画面とコマンドラインの両方に出す。
7. **出どころの `手入力`**（D-040）: 層Aの `source` で `手入力` と `manual` を同じに扱う。書き出すときは `手入力` にする。
8. **信号の情報**: 3 の単位と向きは、E1b で `SignalInfo` を構造化した形（信号の名前、種類、素子ID、正の向き）を、すべての回路（rc_lowpass、rlc_series を含む）に広げて返す。説明の文面はエンジンに持たせない（画面の辞書が持つ）。
9. **表示する信号と内部の信号**（画面仕様の未決17）: 結果の名前のすべてを「表示する信号」と「内部の信号」（例: 平均モデルの `v(sw_avg)`、負荷の段差のゲート）に漏れなく分けて返す。信号の情報に内部の印を持たせる形を勧める。`tests/test_e1b_signals.py` は印の無いものだけを付録A.4 の表と比べる形にする。CSV の「すべての信号」に内部の信号を含めるかは、画面仕様 8章に従う。
10. **表示に使う値**（画面仕様の未決18）: スイッチのオン抵抗 r_on のように、仕様の値ではなくテンプレートが決める値を、テンプレートの表示定義として返す（画面の回路図が値を出すため。画面には値を書かない）。
11. **発散の検出**（基本設計書の作成で見つかった不足）: いまは、有限かどうかを確かめるのは制御器の指令だけで、回路の変数（電圧、電流）が発散しても、そのまま結果を返す。計算の途中で、回路の変数が有限でなくなった、または決めた大きさを超えたら、そこで止め、発散した時刻と変数を番号つきのエラーで返す（画面仕様の付録B の N-RUN-DIVERGED に当たる）。判定は核の外（区切りごと）で行い、核の最内ループの決まりを守る。「決めた大きさ」の決め方と根拠を報告する。
12. **層A の `missing`・`targets`・`source` の扱いを決める**: いまは読むコードが無い（不足は実際の値から判断している）。使う欄と使わない欄を決め、使わない欄は仕様の説明と基本設計書に「予約」と書く。`source` は 7 のとおり読む。
13. **エンジンの文の用語を直す**（D-063 の (7)）: `docs/design/glossary.md` の「エンジンの文で直すもの」の一覧（「段差」→ステップ、「出どころ」→出典、「周期の頭」→周期の先頭、「回路状態」→スイッチング状態の併記 など）を、1 の辞書の日本語に入れる。英語の文も glossary の英語にそろえる。
14. **E1b から引き継いだ軽微**（D-058）: 範囲の外の文（初期ゲインの設計の f_ctrl/f0、Q）に、原因と直し方を添える（`tuning/initial.py`。決まりは画面仕様 0.3-3）。`architecture.md` 4〜5章の見出しの用語（「搬送波の既定は三角波」など）を D-063 にそろえる。
15. **設計書の状態の更新**（D-060）: E1b の統合で `docs/design/basic-design.md` と `accuracy-and-resolution.md` の「統合前（E1b）」が「実装済み」になった。E1g の作業の最初に直し、E1g で変えた節もあわせて直す。

## 受け入れ基準

| # | 基準 | 合格の条件 |
|---|---|---|
| 1 | 番号の網羅 | エンジンとテンプレートが出す注意とエラーのすべてに番号がある（試験で、番号の無い文が出ないことを確かめる）。日英の辞書に全番号がある |
| 2 | 文面の後退なし | 既存の受け入れ試験が見ている日本語の文面が、辞書を通しても変わらない。例外は 13 の用語の是正だけで、その文面を見ている受け入れ試験は、E1g の検証担当が直す（実装担当は直さない） |
| 3 | 進み具合 | 進み具合が単調に増え、最後に1になる。計算が止まっている間隔が 0.2 秒を超えない（20万ステップ以上の計算で測る） **適用の範囲（D-076）**: テンプレートの回路（未知数 100 以下）。それより大きい回路の準備の時間は、既知の限界として基本設計書に書く |
| 4 | 中断 | 中断を求めてから 0.2 秒以内に終わり、途中の結果を返さない **適用の範囲（D-076）**: テンプレートの回路（未知数 100 以下）。それより大きい回路の準備の時間は、既知の限界として基本設計書に書く |
| 5 | 区切りの費用 | 区切った計算と区切らない計算の結果がビット一致。所要時間の増加が 5% 以内 |
| 6 | 変わり目の記録 | 指令で値が決まる電源 → R → C の回路で、指令が変わる時刻の電源の電流が変わる直前の値になる。刻みを半分にしていく誤差の比が 2次を保つ（比 3.5 以上） |
| 7 | テンプレートの注意 | C_esr を省いた降圧コンバータで、注意が `Result.notes`、コマンドラインの表示、CSV と一緒に書き出す注意のファイル（`<CSV の名前>.notes.txt`）の3か所に番号つきで出る。**改訂（D-075）**: CSV そのものには注意の行を入れない（見出し1行 ＋ サンプル数の行。画面仕様 8.4 と同じ形） |
| 8 | 出どころ | `手入力` と `manual` の仕様が同じ結果になり、書き出すと `手入力` になる |
| 9 | 信号の情報 | すべての回路で、結果の信号ごとに単位と正の向きが返る。降圧コンバータは画面仕様の付録A.4 の信号の表と1対1で合う |
| 10 | 内部の信号 | すべての回路で、結果の名前が「表示する」と「内部」に漏れなく分かれる（試験で、どちらにも入らない名前が無いことを確かめる）。降圧コンバータの表示する信号は付録A.4 の表と1対1 |
| 11 | 表示に使う値 | 降圧コンバータの r_on がテンプレートの表示定義から取れ、計算に使った値と一致する |
| 12 | 発散の検出 | 発散する回路（発散する線形の回路と、デューティ比の上下限を外した不安定なゲインの降圧コンバータの状態平均化モデル）で、計算が途中で止まり、時刻と変数の入った番号つきのエラーが返る。安定な回路（既存の受け入れ試験の全部）で誤って止まらない。検出による費用の増加が 5% 以内。**改訂（D-074）**: 上下限のある不安定な降圧コンバータは、デューティ比が上下限に張り付いて有界の振動になり、発散しない。これは止めない（大きさでは判定できず、止めるのは誤り）。不安定であることの判定は、E2a の評価（閉ループ極の絶対値の最大、設計目標の未達）で行う |
| 13 | 層A の欄 | `missing`・`targets`・`source` の扱いが仕様の説明と基本設計書に書かれ、試験がある |
| 14 | 設計書の更新 | `docs/design/basic-design.md` と `accuracy-and-resolution.md` の該当する節（E1b の状態を含む）を更新している（D-060）。`glossary.md` の「エンジンの文で直すもの」が片付いている |
| 15 | 後退が無いこと | `python scripts/check.py` が通る |
