# W2: 自動テストを手元で回せるようにする

担当: tooling-engineer ／ 依存: W1（完了）

## 目的

GitHub上の自動テストに頼らず、手元のPCで「どのコミットが、どのOSで、確認を通ったか」を確かめ、記録として残せるようにする。

背景: 今月の GitHub Actions の無料枠が残っていない（POからの連絡。W1 の確認で多く使った）。GitHub上の自動テストは手で起動したときだけ走る設定に変えた（D2、D-031）。Windowsでの確認は、POのPC（日本語Windowsの実機）で行う。オーケストレーターはPCのフォルダ越しに結果のファイルを読める。

## 範囲

1. **手元の確認の実行と記録** `scripts/local_ci.py`（標準ライブラリだけ、OSに依らない）:
   - 既定では、リモートの最新を取得し、指定したコミット（既定は `origin/main`）をまっさらな作業用の場所に取り出して `python scripts/check.py` を実行する。作業中のフォルダの未コミットの変更に左右されない。`--current` を付けると、いまの作業フォルダの内容で実行する。
   - 結果を `.cycle/ci/` に1回1ファイルで書く。入れるもの: コミットID、ツリーID、ブランチ、未コミットの変更の有無、OS、Python の版、既定の文字コード、通過・失敗・スキップの件数、所要時間、合否、失敗した試験の名前。認証情報、環境変数の中身、試験の出力の本文は入れない。
   - 終了コードで合否が分かる。同じコミットの結果が既にあれば、既定では実行せずにそれを示す（`--force` でやり直す）。
2. **`scripts/doctor.py` の結果にも、コミットIDとツリーIDを入れる**（どの内容に対する確認かが分かるように）。
3. **ハーネスとのつなぎ**: 作業単位の仕様の見出しに `needs_windows: true` と書いたら、統合の条件に「そのツリーに対する、Windowsでの合格の記録」を加える。記録は `python scripts/cycle.py record-ci <ID> --result <ファイル>` で取り込み、ツリーIDが一致しないものは拒む。レビューや検証の後で検証担当が足したファイルの扱いは、既存のゲートと同じ決まりに従う。
4. **定期的に回したい場合の案内**: Windowsのタスク スケジューラに登録する手順を文書に書く（登録するかどうかはPOが決める。スクリプトは登録しない）。
5. **文書**: `docs/design/harness.md`、README、`CLAUDE.md` のコマンド、`milestone-cycle` スキル。GitHub上の自動テストは「手で起動する補助」と位置づける。

## 範囲外

GitHub上の自動テストの再開（来月以降、本線への統合時だけに絞って再開するかはPOの判断）。H2 の指摘。

## 受け入れ基準

| # | 基準 | 合格の条件 | 確かめ方 |
|---|---|---|---|
| 1 | 取り出して実行 | 作業フォルダに未コミットの変更や壊れたファイルがあっても、指定したコミットの内容で確認が走り、結果のコミットIDとツリーIDがそのコミットと一致する | Linuxの手元と、POのPC |
| 2 | 記録の中身 | 結果のファイルが範囲1の項目を持ち、認証情報、環境変数の中身、試験の出力の本文を含まない。失敗させた試験の名前が入る | 試験 |
| 3 | 合否 | 確認が失敗したら終了コードが0でない。合格の記録を偽って作れる経路が無い（確認を実行せずに合格と書く、別のコミットの結果を使い回す） | 試験。1か所ずつ壊して落ちること |
| 4 | ハーネスとのつなぎ | `needs_windows: true` の作業単位は、Windowsでの合格の記録が無い、ツリーIDが違う、OSがWindowsでない、不合格、のどれでも統合できない。記録があれば統合できる | 試験（一時リポジトリ） |
| 5 | Windowsの実機 | POのPCで `python scripts\local_ci.py` が動き、結果のファイルをオーケストレーターが読める | POのPCで1回実行 |
| 6 | 後退が無いこと | `python scripts/check.py` が通る。既存のゲートの決まりが変わらない | 実行 |

許容の根拠: いずれも合否が二値。

## 報告に含めること

- 基準ごとの結果。Linuxの手元で確かめたものと、Windowsの実機が要るもの（基準5）を分ける
- 結果のファイルの例
