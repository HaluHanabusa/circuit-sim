# E1h: 検出（ADC）と PWM のカウンタの量子化を、制御器の部品として選べるようにする

担当: control-engineer ／ 依存: E1f（スイッチングモデルで PWM の段どおりにゲートを切り替える）、E1g（番号つきの注意） ／ 次: E2（ゲイン最適化）

## 目的

いまのシミュレータは、検出値を倍精度のまま制御器に渡し、デューティ比も連続の値で使う（実機より細かい。`accuracy-and-resolution.md` 3.2）。実機の ADC と PWM のカウンタの段は、定常にリミットサイクル（試算で指令値の 0.01〜0.24%）と平均のずれを作り、微分のゲインは検出の 1 段を増幅する（同 3.4）。これが計算に出ないと、E2 の最適化が実機では振れるゲインや雑音に弱いゲインを選ぶ。

E2 の前に、ADC と PWM のカウンタを制御器の部品として入れ、選べるようにする。既定は理想（いまの動きとビット一致）。

## 範囲

1. **検出の部品（ADC）**（`circuit_sim/control/`）: ビット数 n、入力範囲（下端、上端。検出する信号に換算した値。例: 3.3 V の ADC に 1/5 の分圧なら 0〜16.5 V）。
   - LSB = (上端 − 下端)/2ⁿ。符号 = floor((v − 下端)/LSB) を 0〜2ⁿ − 1 で止める（範囲の外は端の符号。飽和）。制御器に渡す値 = 下端 + 符号·LSB。
   - 境目の決まり: v が境目（下端 + k·LSB を倍精度で計算した値）ちょうどなら、上の符号。境目の判定は、この値との比較で決める（割り算の丸めで符号が 1 つずれないようにする）。
   - 飽和した回数と、最初の時刻を数える（注意に出す）。
   - 制御器が測る信号ごとに1つ持てる形にする（E3 のカスケードで、電流と電圧の2つを測る）。
2. **PWM のカウンタの部品**: 段数 N（キャリア1周期でデューティ比が取れる段の数）。段 = floor(d·N + 0.5) を 0〜N で止め、使うデューティ比 = 段/N。
   - 制御器の出力（PID の上下限で止めた後の値）に掛ける。制御器の内部の状態（積分、アンチワインドアップの判定）は、量子化の前の値のまま（ファームウェアが浮動小数点で演算し、比較レジスタに整数を書く形）。
   - 状態平均化モデル（従属電圧源）とスイッチングモデル（PWM）の両方に同じ段のデューティ比が渡る。量子化を制御器の出口に置くのはこのため。
   - クロック周波数から段数を求める関数も置く: のこぎり波 N = f_clk/f_sw、三角波（アップダウンのカウンタ）N = f_clk/(2·f_sw)。整数でなければエラー。高分解能 PWM は、1 段の時間から N = 1/(f_sw·刻み) とする。
3. **制御器への組み込み**: `Controller` の口（`period`、`inputs`、`outputs`、`reset()`、`step()`）を変えずに、既存の制御器に検出と PWM の部品を足せる形。核（`kernel.py`）と `simulate.py` は触らない。足さなければ、いまの制御器がそのまま渡る（理想）。
4. **指令値の扱い**: 既定（層A から作る場合）は、指令値（`Vref`、`Vref_step`）を検出と同じ変換で ADC の段に合わせる（比べる値 = 下端 + floor((r − 下端)/LSB)·LSB）。このとき、積分のある制御で定常が一定になれるのは、ある PWM の段の定常の出力が、指令値の段（零誤差の段。zero-error bin）[下端 + c·LSB, 下端 + (c + 1)·LSB) に入るときだけ（DC 解の存在の条件。Peng, Prodić, Alarcón, Maksimović, "Modeling of Quantization Effects in Digitally Controlled DC–DC Converters", IEEE Trans. Power Electronics, vol. 22, no. 1, 2007。Peterchev, Sanders, "Quantization resolution and limit cycling in digitally controlled PWM converters", IEEE Trans. Power Electronics, vol. 18, no. 1, 2003）。部品は、値のまま比べる形（決めること3の B）も選べる。
5. **スイッチングモデルでの PWM の段**: 量子化したときは、オン時間を 段/N × 周期 ちょうどに置く（E1f の刻みの途中の切り替えの上で）。丸めの余りの持ち越し（D-021）はしない（実機のカウンタは持ち越さない）。E1f の方式で、段を PWM の 1 段の 1/100 より細かく置けない段数は、計算の前にエラーにし、置ける最大の段数を文に書く。
6. **降圧コンバータのテンプレートの項目（層A）**: `buck_voltage_mode` の `control` に、省略できる項目を足す。
   | 項目 | 単位 | 中身 | 決まり |
   |---|---|---|---|
   | `adc_bits` | `1` | ADC のビット数 | 整数。3つ（`adc_bits`、`adc_low`、`adc_high`）は組で入れる |
   | `adc_low`、`adc_high` | V | 出力電圧に換算した ADC の入力範囲の下端と上端 | `adc_low` < `adc_high`。指令値（`Vref`、`Vref_step`）は `adc_low` 以上、`adc_high` 未満 |
   | `pwm_levels` | `1` | PWM の段数 N | 整数。2 以上 |
   - 受け付ける範囲は、試験で確かめた範囲にする（D-062）。案: ビット数 4〜24、段数 2〜（範囲5の上限。最大 2²⁴）。担当が根拠と一緒に決める。
   - 図の素子（`element`）は `PID`（ADC）と `PWM`（段数）にしておく。画面の項目は A2 で決める（ux-designer）。
   - 版は 0.3 に上げる（決めること2）。0.1 と 0.2 のファイルは今までどおり読める。書くときは 0.3。0.2 と書いたファイルに量子化の項目があったときの扱い（受けるか断るか）は担当が決め、決定記録の案を報告に書く。
7. **量子化の要約**（E2 が使う）: 展開した結果から、量子化の条件を1か所で返す。
   - LSB [V]、PWM の 1 段のデューティ比 1/N と出力電圧 Vin/N。
   - 指令値（`Vref`、`Vref_step` のそれぞれ）の零誤差の段と、その段に入る PWM の段（DC 解があるか）。定常の出力は V_k = (k/N)·Vin·R/(R + r_on)（状態平均化モデルの定常。ESR は直流に効かない）。
   - 検出の 1 段あたりの操作量の動き: (Kp + Ki·Ts + Kd/(Tf + Ts))·LSB（PID の差分方程式に偏差の 1 段のステップを入れた最初のサンプルの出力）と、それが PWM の何段に当たるか。
   - 量子化が無い（理想）なら、そうと分かる値（計算の前提に「検出と PWM は理想（量子化なし）」と書ける形。`accuracy-and-resolution.md` 5.2 の5）。
8. **注意**（E1g の番号と差し込む値で返す）: 指令値を ADC の段に合わせた（元の値、段の範囲）。ADC の入力範囲の外に出た（回数、最初の時刻）。DC 解が無い指令値がある（定常にリミットサイクルが残る）。検出の 1 段で操作量が PWM の 1 段以上動く（実機では雑音にも同じ倍率が掛かる）。
9. **変換の時刻**: 部品に欄を置き、値は「制御周期の先頭」だけを受ける（決めること1の A）。
10. **設計書の更新**（D-060）: `accuracy-and-resolution.md`（1章の8、3.4 の表に「指令値は値のまま」の前提を明記し、符号に合わせた場合の結果を足す、4章、5.2 の5、6章の7）、`basic-design.md`（5.1 の版と項目、6.3、6.6、15.1、15.2）、`requirements.md`（NFR-02、X-7 の状態）、`glossary.md`（ADC、LSB、入力範囲（フルスケール）、零誤差の段、DC 解。出典を確かめて書く）。

## 範囲外

- 変換の時刻の選択（決めること1の B）、ADC の雑音、アンチエイリアスのフィルタ、変換にかかる時間（演算遅れ 1 制御周期の中に収まるとみなす）。
- 制御器の演算の語長（固定小数点、単精度）。ディザ。高分解能 PWM の端の置き方の細部（片側だけ動く、など）。
- 量子化を線形化に入れること（E2 は量子化を利得 1 とみなして余裕を計算する。E2 の仕様）。
- 画面（項目の見せ方、注意の文言の配置）。A2 で ux-designer が決める。

## 受け入れ基準

基準の回路は E1b と同じ（同期整流の降圧、Vin 24 V、L 47 µH、C 100 µF、R_load 6 Ω、f_sw = f_ctrl = 100 kHz、同梱の例のゲイン）。ADC の入力範囲は、断りが無ければ 0〜16.5 V（12 ビットで LSB 4.028 mV。S1 の試算と同じ置き方）。定常は、40 ms 計算して最後の 10 ms で見る。

## 依存

- **E1f**: 範囲5と基準8は、ゲートの切り替えを刻みの途中に置けることが前提。E1f が「端数を細かく量子化する」方式なら、その細かさで受け付ける段数の上限が決まる（範囲5）。状態平均化モデルの部分（範囲1〜4、6、7、基準2〜7、9〜11）は E1f の前に進めてよい。
- **E1g**: 注意を番号と差し込む値で返す（範囲8）。E1g が先に統合されていない場合は、E1g の形に合わせて足せるよう、注意の中身（何を差し込むか）を報告に書く。
- E1b（完了）: PID、レグ、テンプレート。

## 引き継ぎ

1. **E2 へ**: 範囲7の要約（DC 解の有無、検出の 1 段あたりの操作量）。E2 は量子化した構成で、状態平均化モデルの最適化とスイッチングモデルの確認の両方を行い、要約を結果に載せる。
2. **E2 へ**: 指令値を段に合わせると、定常の平均が零誤差の段の中で動く（基準5の下書きの測定で、12.0 V で −2.0〜−2.9 mV）。E2 の定常偏差の判定は、この分を含めた量（スイッチングモデルの実測）で行う。
