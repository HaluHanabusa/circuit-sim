# I0: 読み取りの土台（評価、セル単位の共通テキスト、表の取り出し、照合の核）

担当: ingest-engineer ／ 依存: なし ／ 次: I1a〜I1d、I2a、I2b（`docs/research/extraction-approach.md` 8章）

## 目的

設計書とデータシートから素子の設定を作る機能（D-068 の (4)）の、最初の一歩。生成 AI を使わない経路と、誤りに気づく仕組みを先に作る。
AI をつなぐ前に、評価の土台と照合を持つ。照合が無いまま AI をつなぐと、誤りを測る手段が無い（`extraction-approach.md` の結論）。
この作業は、AI も、PO の判断も、ほかの検討の結果も要らない。計画をどう組み直しても使う部分。

## 範囲

1. **評価の土台**: 模擬資料（データシート風の PDF と Excel）を生成する台本と、その正解。書式の違い（罫線の有無、結合セル、脚注、2段組み、品番ごとの列、日本語と英語、単位の書き方）を組み合わせる。記載の無い項目をわざと入れる。採点（記載のある値の正解率、出した値の正しさ、付け違い、作り話、null の正しさ、読めなかったものの検出）。実在の資料は使わない（著作権）。
2. **共通テキスト**: PDF（文字のあるもの）と Excel を、セル単位（行と列）の位置ラベルつきの共通テキストにする。画像だけのページは「読めなかったもの」の一覧に出す。
3. **表の取り出し**: データシートの電気的特性の表を読み、見出しから列（Min / Typ / Max、条件、単位）を決める規則。決めきれない行は「あいまい」と判定して、値にしない（推測で埋めない。決まり4）。
4. **照合の核**: 値を「候補」として受け取り、共通テキストの該当するセルに、同じ数字・単位・条件があるかを確かめる。単位と次元の検査（`circuit_sim/units.py` を使う）。通ったものだけを値にし、値ごとに照合の状態を持つ。
5. **依存のライセンスの検査**: 入れた配布物（ホイール）の中のライセンスの文書まで読み、同梱物のライセンスを一覧にする道具（`scripts/`）。メタデータの表示だけを信じない。3段階（○ / △ / ×）で判定する。
6. **設計書の更新**（D-060）: `docs/design/basic-design.md` の取り込みの節と、`glossary.md`。

生成 AI は呼ばない（プロバイダ層は I2b）。Word、本文の読み取り、グラフの数値化、メーカーのモデルの取り込みは、次の作業単位。

## 依存の決まり（D-069）

- 使うのは、判定が ○ のものだけ（`extraction-approach.md` の一覧: pypdf、openpyxl、標準ライブラリなど）。pdfplumber の表の部分は、MIT の表示つきで取り込む形なら可（Pillow と pypdfium2 は入れない）。
- △ のもの（Pillow、pypdfium2、lxml など）は、PO の判断が出るまで使わない。× は使わない。
- 足した依存は、ホイールの中の文書を確かめた結果を、報告と `docs/design/dependencies.md`（無ければ作る）に書く。

## 受け入れ基準

| # | 基準 | 合格の条件 |
|---|---|---|
| 1 | 誤りを出さない | 模擬資料 30 件・450 値以上で、「読み取った」と返した値の誤りが 0、付け違いが 0。回収率（記載のある値のうち読み取れた割合）を、書式ごとに記録する |
| 2 | 推測で埋めない | 記載の無い項目を、すべて null のまま返す（作り話 0）。あいまいな行を値にしない |
| 3 | 読めないものを隠さない | 画像だけのページと、読めなかった表が、一覧に出る |
| 4 | 照合 | 仕込んだ誤り（桁、単位、接頭語、条件、行の取り違え、列の取り違え＝Max を Typ として出す、文書に無い値）を、照合がすべて検出する |
| 5 | 位置 | 値ごとに、ファイル、ページ（またはシート）、表、行、列が分かる |
| 6 | 再現性 | 同じ入力から同じ結果（別のプロセス、`PYTHONHASHSEED` を変えても同じ） |
| 7 | AI を使わない | 試験と実行の経路に、AI の呼び出しが無い。本物の `claude` を起動しない（決まり11） |
| 8 | ライセンスの検査 | メタデータは緩いライセンスを名乗るが、同梱物に LGPL の文書を持つ配布物（試験用に作った偽の配布物）を × と判定する。いまの依存（numpy、scipy ほか）の判定の一覧が出る |
| 9 | 端末の外に出さない | 読み取りの経路に、外部への通信が無い（決まり9） |
| 10 | 後退が無いこと | `python scripts/check.py` が通る。設計書を更新している |
