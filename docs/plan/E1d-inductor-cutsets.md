# E1d: インダクタだけで外とつながる部分を解く

担当: solver-engineer ／ 依存: E1c ／ 次: E3（三相インバータ、DCモーター）

## 目的

インダクタだけで残りとつながる部分（インダクタの切断集合）があると、インダクタ電流の和が0に縛られ、その部分の電位が決まらない（指数2の微分代数方程式）。いまは「解けない回路」として断っている。三相インバータの星形RL負荷の中性点、中性点を接地し直流側を浮かせた三相ブリッジ、直列のインダクタがこれに当たる。E3 の前に解けるようにする。

## 範囲

- インダクタの切断集合（と、双対のコンデンサと電圧源だけのループ）を見つけ、回路を変えずに解く。人工の抵抗を足して解く方法は、結果が変わる大きさを報告し、許容差以内であることを示せる場合に限る。採った方法と理由を決定記録の案として報告する。
- 初期値が拘束を破る（インダクタの初期電流の和が0でない）ときは、推測で直さずエラーにする（どの素子の、どの和が、いくつか）。
- 拘束で決まる変数（浮いた節点の電位）に、台形則の数値振動が出ないこと。
- エラー文の「直列のインダクタは1つにまとめる」などの、いまの直し方の案内を、解けるようになった回路では出さない。

## 受け入れ基準

| # | 基準 | 合格の条件 |
|---|---|---|
| 1 | 直列のインダクタ | 2つの L の直列が、1つにまとめた回路と同じ結果（信号の代表値の 0.1% 以内） |
| 2 | 星形RL負荷 | 三相の正弦波電源 ＋ 中性点が浮いた星形RL負荷の定常の相電流が、フェーザで求めた値と 1% 以内。中性点の電位も解析解と一致 |
| 3 | 浮いた直流側 | 中性点を接地し直流側を浮かせた三相ダイオードブリッジが、E1c の基準1と同じ範囲（10〜400 V、初期値ゼロ）で計算でき、直流側の平均が理論値と 2% 以内 |
| 4 | 拘束を破る初期値 | インダクタの初期電流の和が0でないとき、素子名と和を示すエラーになる |
| 5 | 数値振動なし | 浮いた節点の電位に、刻みごとに符号が変わる振動が出ない |
| 6 | 2次精度 | 状態量の誤差が、刻み半分で約1/4 |
| 7 | 後退が無いこと | 既存の試験がすべて通る。`python scripts/check.py` が通る |
