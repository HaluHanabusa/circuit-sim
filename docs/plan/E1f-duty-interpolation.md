# E1f: デューティの分解能（ゲートの切り替えを刻みの途中で扱う）

担当: solver-engineer ／ 依存: E1b ／ 次: E2（ゲイン最適化）

## 目的

ゲートの切り替え時刻を時間刻みの格子に丸めているため、デューティの分解能が「1 / 1周期の分割数」に限られる。目標が格子のすぐ近くだと出力が最大1.1%振れる（D-021、D-036）。E2 の評価を乱さないよう、切り替えを刻みの途中で扱う。

## 範囲

- ゲートの切り替えが刻みの途中にあるとき、その刻みを切り替えの前後に分けて進める（回路状態ごとに、分けた刻みの行列を用意して使い回す。端数を細かく量子化するか、正確な端数で求めるかは担当が決め、精度と記憶量を報告する）。
- ダイオードの切り替え（状態で決まるもの）は、従来どおり格子で扱ってよい。
- 丸めの余りの持ち越し（E1a の C）は、この仕組みで不要になるなら外す（外したことを報告）。
- 核の最内ループの決まりを守る。

## 受け入れ基準

| # | 基準 | 合格の条件 |
|---|---|---|
| 1 | 分解能 | 受け入れ試験に残っている `xfail(strict)`（E1c の範囲9、`test_c16`）が通る。検証担当Bの最悪点（目標 11.99225 V）を含め、目標を格子の近くで細かく振って、出力の周期平均の振れが指令値の 0.2% 以内（E2 の整定の許容帯 ±1% の 1/5。D-063） |
| 2 | 精度 | 切り替えが格子に乗る場合、結果が今と一致する（差は丸め誤差の範囲）。刻みを半分にしたとき誤差が約1/4（2次精度）が保たれる |
| 3 | 費用 | 基準の降圧回路（E1a）で、所要時間の増加が 50% 以内。記憶量の見積もり（上限の判定）に、増えた行列が入っている |
| 4 | 後退が無いこと | E1a、E1b、E1c の基準が引き続き合格。`python scripts/check.py` が通る |
