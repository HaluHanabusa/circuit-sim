# A0: アプリの骨組み

担当: ui-engineer（実装）、ux-designer（UX確認） ／ 依存: A0s（画面仕様、完了） ／ 次: A1（開く、仕様パネル、回路図、実行、スコープ）

## 目的

`circuit-sim` コマンド1つでローカルのサーバーが起動し、ブラウザで作業画面の枠が開く。以後の画面（A1〜）を載せる土台を、画面仕様とデザインの基準どおりに作る。

## 範囲（画面仕様 `docs/design/screens-v0.1.md` の章）

- 1章 全体の枠（S0）、3章 起動直後（S1）、9章 お知らせ（S7）の仕組み、10章 言語とテーマ（S8）
- 2章 数値の表記と入力の共通部品（工学表記の表示と読み取り）。A1 で使う
- `docs/design/design-system.md` の色、文字、寸法、基本部品を、画面全体の設計トークンとして実装する
- 12章のうち D1（サンプルの一覧）、D8（つながっているかの確かめ）
- 起動コマンド `circuit-sim`: 127.0.0.1 の空いている番号でサーバーを起動し、既定のブラウザで開く。`--no-browser`、`--port`。止めるときの扱い（未決11）を決めて報告する
- パッケージ: 画面のビルド結果を Python パッケージに同梱する。利用者に Node.js は要らない

範囲外: 開く（S2）、仕様パネル（S3）、回路図（S4）、実行（S5）、スコープ（S6）。これらは A1。

## 技術の決まり（D-006、D-041）

- サーバー: FastAPI ＋ uvicorn。画面: React ＋ TypeScript ＋ Vite。依存は MIT / BSD / Apache-2.0 だけ。足した依存とライセンスを報告する。
- 画面のビルド結果（`circuit_sim/app/static/`）はリポジトリに入れる。Node.js の無い環境（POのPCを含む）でも、Python の試験とアプリの起動ができるようにするため。ビルド結果がソースと食い違っていないことを確かめる仕組みを作る（Node.js がある環境の `scripts/check.py` で確かめる。無い環境では確かめなかったことを結果に残す）。
- 外部のCDNやネットワークに依存しない。フォントも同梱するか、OSのフォントを使う。
- 文言は直書きせず、日本語と英語の辞書から引く（画面仕様の文言キー）。
- 画面の自動テスト: 部品の試験（vitest など）と、実際のブラウザでの通し試験。この作業環境には `/usr/bin/google-chrome` と Python の playwright がある。
- **本物の `claude` を起動しない**（CLAUDE.md 決まり11）。試験は `PATH=/usr/local/bin:/usr/bin:/bin` に、使う道具（node）の場所を足して流す。

## 受け入れ基準

| # | 基準 | 合格の条件 |
|---|---|---|
| 1 | 画面仕様 | 1章、3章、9章、10章の受け入れ基準（AC-1-*、AC-3-*、AC-9-*、AC-10-*）を、実際のブラウザで1つずつ確かめる。確かめられないもの（A1 の画面が要るもの）は、理由を書いて A1 に送る |
| 2 | 起動 | まっさらな仮想環境に `pip install` して `circuit-sim` を実行すると、5秒以内にブラウザで作業画面が開く。ネットワークを切っても同じ |
| 3 | 4つの状態 | 起動直後の画面とお知らせに、読み込み中・空・正常・エラーの見え方がある。サーバーを止めると 5 秒以内に「つながっていない」と分かる（D8） |
| 4 | 言語とテーマ | 日本語 / 英語、明 / 暗の4通りで、文字があふれず、コントラストが `design-system.md` の基準を満たす（自動で測る） |
| 5 | 数値の部品 | 画面仕様2章の入力規則の例（AC-2-*）を、部品の試験ですべて確かめる |
| 6 | 直書きなし | 画面の文言に直書きが無い、色の直書きが無いことを、自動の試験で確かめる |
| 7 | Windows | POのPCで `python scripts\local_ci.py --ref origin/A0` が合格する。加えて、POのPCで `circuit-sim` を起動して画面が開く（オーケストレーターがPOに頼む） |
| 8 | 後退が無いこと | `python scripts/check.py` が通る |

## 報告に含めること

基準ごとの結果、4つの状態と4通りの言語・テーマの画面の画像の場所、足した依存とライセンス、未決11の扱い、A1 に送ったもの。
