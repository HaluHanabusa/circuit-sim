# A4s: 降圧コンバータの画面仕様の確定（画面仕様の付録A.4）

担当: ux-designer ／ 前提: E1b（降圧コンバータのテンプレート） ／ 次: A0 の修正、A1

## 目的

A0s で仮置きにした付録A.4（降圧コンバータ `buck_voltage_mode` の仕様パネル、回路図、信号、精度の切り替え）を、E1b の実装に合わせて確定し、A1 がそのまま実装できる具体さにする。

## 成果物

- `docs/design/screens-v0.1.md` 付録A.4: 項目と計算の設定（範囲、組で入れる値、既定と自動の値）、信号（スイッチング / 平均）、回路図（2通り）、文言（日英のキーの表）、お知らせの追加、未決の更新
- `docs/design/design-system.md` 8章: 回路図の寸法と描き方の補足

## 受け入れ基準

1. 付録A.4 の項目・信号の名前が、E1b のテンプレートが出す項目・信号と1対1で対応する。
2. 精度（スイッチング / 平均）の切り替えの見せ方と、平均モデルに無い信号の扱いが決まっている。
3. 新しい文言が日英のキーの表で書かれ、辞書の生成（`strings_from_spec.py`）が拾える形になっている。
4. `python scripts/check.py` が通る。

## 引き継ぎ

- 統合すると表の文言が増える。A0 は main を取り込んだ後、辞書を作り直し（`strings_from_spec.py --write`）、画面をビルドし直す。
