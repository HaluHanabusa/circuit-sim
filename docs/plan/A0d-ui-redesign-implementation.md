# A0d: 新しい見た目（B 案）の実装

担当: ui-engineer（実装）、ux-designer（UX 確認） ／ 依存: A0（統合済みであること）、A0r（デザインの基準と画面仕様の第2版）／ 次: A1（開く、仕様パネル、回路図、実行、スコープ）、A2 の一部（設計目標、評価）

状態: **下書き**（ux-designer が A0r の範囲3で書いた。オーケストレーターが確定する）。

## 目的

A0 の骨組み（枠、起動直後、お知らせ、言語とテーマ、数値の部品）を、PO が選んだ B 案（D-072）の見た目に作り替える。A1 以降の画面を、この上に載せる。
PO の指摘（字が小さい、強弱が無い、空きが多い。D-055）を、設計トークンと枠の段階で直し、Windows の実機の字体で確かめられる状態にする。

正は `docs/design/design-system.md`（第2版）と `docs/design/screens-v0.1.md`（第2版）。見本（`docs/design/mockups/direction-b/`）は参考で、食い違う所は設計書に従う。

## 前提と、統合の順番

1. **A0 が main に統合されていること。** このブランチは、A0 を統合した後の main から作る。
2. **A0r の文書（第2版）は、この作業単位と一緒に main に入れる。** A0 の試験は、設計書の表と実装を照らし合わせている。
   - `tests/test_app_strings.py`（辞書 ＝ 画面仕様の文言の表）
   - `tests/test_app_design_tokens.py`（`tokens.css` ＝ `design-system.md` の 2.1・2.2・3.1 の表、2.3 のコントラスト）

   第2版の文書だけを main に入れると、A0 のこの2つの試験が落ちる。A0 だけを先に入れた main に、A0r の文書だけを入れても同じ。**文書と実装を同じブランチで合わせてから統合する。**
3. このブランチの最初の作業: main（A0 を統合済み）に `origin/A0r` を取り込む。`docs/design/design-system.md` の 3.1・3.2（波形の色の表）は、A0 の直し（暗の赤 `#f62411`）と第2版の両方が触っているので衝突する。**第2版の側を採る**（A0 の直しを含み、暗いテーマの数値を新しい面の色で計算し直してある）。

## 範囲

`docs/design/screens-v0.1.md` の 0.3、1章（全体の枠）、3章（起動直後）のうち左の列と右の見出しの行、9章（お知らせ）、10章（密度、言語、テーマ）と、`docs/design/design-system.md` の全部。

A0 の範囲に無かった領域の中身（仕様パネルの表、回路図、スコープ、設計目標、評価、信号と読み取り、起動直後のサンプルの中身）は作らない（A1、A2 の一部）。ただし、その領域の**枠**（見出し行、境の線、列の幅、たたむ、仕切り）は、この作業単位で第2版の形にする。

**4. 文言と辞書。**

- `frontend/tools/strings_from_spec.py --write` で、第2版の表から辞書を作り直す。main の画面仕様からの増減: 外れるキー 5（`sample.rc.*`、`sample.rlc.*`、`spec.targets.ignored`）、足すキー 147、文が変わるキー 51（用語の直し）。
- 数値と単位の間を改行されない空白にする決まり（`UNIT_SPACE`）に、`%`、`deg`、`dB` を足す。
- A0 のサンプル（`circuit_sim/app/samples/rlc_series.json`、`sample.rlc.*`）は、降圧コンバータのサンプルに替える。降圧コンバータの仕様を開く口と中身が A1 まで無い間の扱い（A0d の間は、いまのサンプルを残して枠だけを見るか）は、ui-engineer が決めて報告する。
- `EXTRA`（画面仕様の表の外に持っている文言: `app.unauthorized`、`N-PREFS-SAVE`、テンプレートの表示名）は、そのまま残す（画面仕様への追記は A1 の仕様。`screens-v0.1.md` 14章の未決28）。

**5. 試験。**

- `tests/test_app_design_tokens.py`: 色の数（2.1 が 19、2.2 が 6 状態 × 3、3.1 が 8）と値を第2版に。字体の指定が 4.1 と一字一句同じ、を足す（`design-system.md` 10章の 7）。
- `tests/test_app_browser.py`、`tests/data/measure_layout.js`: 寸法と配置の期待値を第2版に。次を足す。
  - 画面に出ている文字の大きさの検査（`design-system.md` 10章の 8）
  - 同じ色だけの最大の矩形の割合（`design-system.md` 11.3 の 3）
  - 3列と2列の切り替え、密度の切り替え、表示倍率のお知らせ
