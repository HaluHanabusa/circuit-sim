# A0s: v0.1 の画面仕様とデザインの基準

担当: ux-designer ／ 次: A0（骨組みの実装）、A1（スコープと実行画面の実装）

## 目的

v0.1（A0 と A1）の画面を、ui-engineer がそのまま実装できる具体さで決める。

## 成果物

- `docs/design/screens-v0.1.md`: 画面ごとの用事、配置、4つの状態、操作、文言（日英）、測れる受け入れ基準
- `docs/design/design-system.md`: 色（明暗）、波形の色、文字、寸法、基本部品、動き
- `docs/design/app-design.md` の改善

## 受け入れ基準

| # | 基準 | 合格の条件 |
|---|---|---|
| 1 | 画面仕様の網羅 | 起動直後、開く、仕様パネル、回路図、実行、スコープ、お知らせ、言語とテーマのそれぞれに、役割の定義にある6項目が書かれている |
| 2 | 色の根拠 | 波形の色と状態の色について、明暗の両テーマでコントラストと見分けやすさを計算した根拠が書かれている |
| 3 | 確認 | オーケストレーターが構成と抜き取りで確認する。文書だけの作業なので、ゲートは implement と check。画面の合否（ux）は実装後の A0 / A1 で判定する |
