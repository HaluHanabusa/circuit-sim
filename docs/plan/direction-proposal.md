# 方向の提案（D-068・D-069 を受けた検討のまとめ）

最終更新: 2026-11-16 ／ 書いた人: オーケストレーター ／ 状態: **凍結（D-071）**。PO の判断は「まず、絞った v0.1 を完成させる。独自の部分は教育用の VR ワールドを第一候補にする」。この文書の3つの案と P1〜P5 は、v0.1 の反応を見てから改めて扱う
材料: `docs/research/` の4つの検討（既存の道具との比較、研究・教育向けの拡張、読み取りの方式、素子と解法）。
割合（既存 / 自作）は工数の見積もりで、測ったものではない。

## 1. 結論

1. **独立した道具として作る理由は残る。ただし狭い。** 差別化の2つ（設計書から設定を作る / 設計目標からゲインを求めて検証する）は、機能としては他にもある。他に見つからなかったのは、それを「ローカルで、緩いライセンスで、出典と未達を隠さずに、一続きに行う」こと。
2. **使える既存の回路エンジンは無い。** 成熟した SPICE 系（ngspice ほか）は、どれもライセンスの決まり（D-069）を通らない。緩いライセンスの区分線形のパワエレ向けエンジンも見つからなかった。エンジンは差別化ではないが、作るしかない。だから**範囲を広げすぎない**。
3. **勧めは案1（絞る）。** 「設計を閉じる層」を中心に置き、エンジンは2つの水準（系統 / 素子）で持つ。D-068 の4点には、3章の形で答える。
4. **PO の判断が先に要るのは、ライセンスの決まりの当て方**（5章の P1）。文字どおりに当てると、いまの依存の NumPy と SciPy も外れ、どの案も成り立たない。

## 3. 3つの案

| | 案1 絞る（勧め） | 案2 素子の水準まで全部自作 | 案3 既存の道具の拡張 |
|---|---|---|---|
| 中身 | 「設計を閉じる層」（出典つきの取り込み → 仕様 → ゲイン → 検証 → 未達）が中心。エンジンは2つの水準。電動機は式の水準で別に解く | 任意の回路を、寄生容量つきの素子で、長い時間、電動機も同じ回路で計算する | PLECS や Simulink の上に、「設計を閉じる層」だけを載せる |
| 既存の割合 | 35〜45% | 25〜30% | 65〜75% |
| 自作 | 55〜65% | 70〜75% | 25〜35% |
| 得るもの | 差別化の部分に工数を寄せられる。止まらない・決定的な計算を保てる | 1つの計算で何でも見られる | 自作が最も少ない。成熟したエンジンと素子 |
| 失うもの | 寄生容量と制御の相互作用を、長い時間で1つの計算として見ること。SPICE の水準の任意の回路 | 工数。SPICE 型は設定で止まる（事実 8）。LTspice・PLECS が最も強い所で並ぶことになる | 利用者に商用のライセンスが要る（PLECS は €7,000〜）。「無料で、緩いライセンスで」が消える。MATLAB の既存の機能と重なる |
| ライセンス | P1 を許せば組める | 同じ | ngspice の上に載せる形は ×。商用の道具は各社の使用許諾 |

案3 のうち「利用者が自分で入れた無料の道具（LTspice など）を、外部の計算機としてつなぐ」形は、案1 に後から足せる（層A と層B を分けた設計と合う）。足すかどうかは後で決められる。

## 4. 案1 での、D-068 への答え方

| D-068 の点 | 答え方 | 限界 |
|---|---|---|
| (1) テンプレート方式をやめる | 層A に回路の記述（素子と接続）を持たせ、回路図エディタで描けるようにする。解けない回路は計算の前に検出して、直し方を案内する。テンプレートは出発点の例として残す | 系統の水準（区分線形）の素子で描ける回路 |
| (2) MOSFET・IGBT と寄生容量 | **素子の水準**: 寄生容量、ゲートの駆動、配線のインダクタンスを入れた非線形の計算を、短い窓（ダブルパルス試験）で行い、切り替えの波形、サージ、E_on・E_off を出す。**系統の水準**: その結果かデータシートの損失の曲線を「損失の表」として引き、熱回路で温度まで出す | スイッチングの過渡が制御に乗る様子を、秒の桁で1つの計算として見ることはできない |
| (3) 大学の水準の素子ひと通り | 約40種を一覧にした。約30種（順電圧つきのダイオードと IGBT、結合インダクタ、変圧器、従属電源、サイリスタ類、オペアンプ、コンパレータ、損失の表、熱回路）は系統の水準。約10種（ショックレーの式、接合容量、MOSFET の静特性と容量、IGBT のテール電流、逆回復）は素子の水準 | 入れないもの: 伝送線路、磁気のヒステリシス、BSIM、メーカーの SPICE モデルの読み込み（ライセンスと暗号化） |
| (4) 設計書を読んで自動で設定 | スクリプトが主。生成 AI は本文とあいまいな行だけで、出した値はコードが資料のセルと照合する。値ごとに、出典、取り出した者、照合の状態を持つ | 画像だけのページとスキャンは対象外（読めなかったものとして一覧に出す） |
| 研究・教育（誘導機、仮想の素子） | 誘導機は3段（等価回路の定常解析 → 回転座標の平均モデル → 回路とつなぐ）。仮想抵抗・仮想容量・仮想同期発電機は、制御ブロックの拡充（伝達関数、座標変換、PLL）で表す | 電動機と半導体の寄生容量を同じ回路で見ることはしない |

残る差別化: (a) 緩いライセンスでローカルに閉じた一続き、(b) 出典を持ち、推測で埋めず、未達を隠さない規律、(c) MATLAB や PSIM を持たない設計者と学生が無料で使えること、(d) データシートから照合つきで素子の設定を作ること。どれも「組み合わせと作り方」の差で、MathWorks などの動きで縮む可能性がある。
