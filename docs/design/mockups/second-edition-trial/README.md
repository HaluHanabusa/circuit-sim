# 第2版の試し描き（設計目標の群と評価）

最終更新: 2026-11-16 ／ 責任者: ux-designer ／ 作業単位: A0r

B 案の見本（`../direction-b/`）には、設計目標と評価が無い（見本は、v0.1 の範囲を絞る決定 D-071 より前に作った）。
画面仕様の第2版で足した「設計目標」の群（`../../screens-v0.1.md` 15章）と「評価」（16章）が、B 案の寸法で収まるかを確かめるために、
見本の `B-buck.dc.html` を元にして、ux-designer が描いたもの。

**試し描きは参考で、正ではない。PO が見て選んだものでもない。** 正は `../../design-system.md` と `../../screens-v0.1.md`。

## 入っているもの

| ファイル | 画面 |
|---|---|
| `trial-buck-evaluation.html` | 降圧コンバータのサンプルを開いて実行した後（3列）。仕様パネルに設計目標の群、右の列に評価と、信号と読み取り。明るいテーマ |
| `trial-buck-evaluation-dark.html` | 同じ画面の暗いテーマ |

## 見方

- ファイルをブラウザ（Chrome か Edge）で開く。ほかのファイルは要らない。外部への通信は無い。
- ウィンドウの中身を 1920×1080、表示倍率 100% にして見る（`../../design-system.md` 11.1）。
- 絵で、操作はできない。

## 確かめたこと

| 確かめたこと | 結果 | 設計書の場所 |
|---|---|---|
| 1920×1080・標準の密度で、同梱サンプルの評価の 9 行（未達の量の行を含む）が、スクロールせずに見える | 見える（評価の節の高さ 656。残りの 345 に、A・B・Δ と信号2つ分） | 画面仕様 1.2、16.2、AC-16-1 |
| 仕様パネルの設計目標の行で、種類の名前が省略されない | 幅 480（3列）でも 380（2列）でも、省略も折り返しも無い | 画面仕様 15.2、AC-15-1 |
| 未達の行が、達成の行より目立つ | 未達の行にだけ、札と量の行が付く。白黒にしても、行の数と記号の形で見分けられる | 画面仕様 16.2、`design-system.md` 6.12 |

初めの案（1つの設計目標を、名前・値・補足の3行で見せ、どの行にも右端に札を置く）は、この試し描きで、9 行の高さが 770 になり、
2つの未達の量が評価の中のスクロールの下に隠れると分かったので、捨てた（画面仕様 16.2）。
設計目標の行の項目に「種類（場面）」を1行で書く案も、既定の幅で末尾が省略されて「オーバーシュート…」が2行並ぶと分かったので、
場面を小見出しにした（画面仕様 15.2）。

## 設計書と違う所、描いていない所

- **数値は見込みの値で、計算した結果ではない。** 評価の実測の値は、E2 の仕様の下書きにある測定（整定時間 1.20 ms、電圧変動 0.637 V）と、置いた値。評価のエンジン（E2a）は、まだ無い。
- 波形は、見本と同じ（ステップの無い、終了時刻 8.62 ms の結果）。仕様パネルの終了時刻（26.62 ms）や、評価の場面（9 ms と 18 ms のステップ）とは合っていない。
- 幅 1600px 未満の配置（波形の下の表の「評価 ／ 読み取り」の切り替え）、密度「詰める」、初期ゲインの面、「選ぶ」のメニュー、空の状態、古い結果、判定できないの行は、描いていない。幅 1600px 未満で開くと、見本と同じ2列になり、評価は出ない（仕様パネルの設計目標の群だけが、第2版の形で出る）。
- 回路図は見本のまま（負荷ステップの素子の描き方は、画面仕様 付録A.4）。
