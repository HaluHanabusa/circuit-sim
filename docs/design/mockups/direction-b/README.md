# B 案「一覧」の見本

最終更新: 2026-11-16 ／ 責任者: ux-designer ／ 作業単位: A0r

画面の見た目の方向として PO が選んだ案（D-072）の見本。PO が Windows の PC のブラウザで見て選んだときのファイルを、そのまま置いてある。

**見本は参考で、正ではない。** 正は `../../design-system.md`（色、文字、寸法、部品）と `../../screens-v0.1.md`（配置、操作、文言、受け入れ基準）。見本と設計書が食い違う所は、設計書に従う。

## 入っているもの

| ファイル | 画面 |
|---|---|
| `B-start.dc.html` | 起動直後（仕様を開いていない）。明るいテーマ |
| `B-buck.dc.html` | 降圧コンバータのサンプルを開いて実行した後。明るいテーマ。カーソル A・B を出した状態 |
| `B-buck-dark.dc.html` | 同じ画面の暗いテーマ |

- 波形は、E1b のコードで計算した本物の結果（終了時刻 8.62 ms、時間刻み 50 ns）を、画素の列ごとの最小・最大で描いたもの（`../../research-ui-v2.md` 7章）。
- 幅 1600px 以上で3列、それ未満で2列になる。高さ 800px 以下では、回路図の見出し行が出ない。

## 見方

- ファイルをブラウザ（Chrome か Edge）で開く。ほかのファイルは要らない（先頭で読もうとする `support.js` は、見比べ用のキャンバスの部品で、無くても同じに描かれる）。外部への通信は無い。
- **ウィンドウの中身を 1920×1080、表示倍率 100%（Ctrl+0）にして見る。** 字体は端末のものを使うので、Windows で見たときだけ、PO が見たのと同じ字体（Segoe UI、Yu Gothic UI、Cascadia Mono か Consolas）になる。
- 見本は絵で、操作はできない。

## 設計書と違う所

見本は、v0.1 の範囲を降圧コンバータ1つに絞る決定（D-071）より前に作った。主な違い:

| 見本 | 設計書 |
|---|---|
| 起動直後のサンプルが3つ（RCローパス、直列RLC、降圧コンバータ） | v0.1 のサンプルは降圧コンバータだけ |
| 設計目標と評価が無い。右の列の上は「結果」 | 仕様パネルに「設計目標」の群、右の列の上に「評価」 |
| 用語が直す前のもの（出どころ、段差、ステップ数） | 出典、ステップ、計算ステップ数（`../../glossary.md`） |
| 起動直後の「開く」のボタンが、右の面のいちばん下 | 右の面の見出しの行（1280×720 でも見えるように） |
| 仕様パネルの幅 460px | 480px（「元に戻す」のボタンの列を取る） |

全部の一覧と理由は、`../../design-system.md` 12章（数値）と `../../screens-v0.1.md` 0.4（配置）。
