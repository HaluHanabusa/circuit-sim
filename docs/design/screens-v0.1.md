# 画面仕様 v0.1（A0・A1）

最終更新: 2026-11-15 ／ 責任者: ux-designer ／ 実装: ui-engineer
関連: `app-design.md`（原則と品質の基準）、`design-system.md`（色・文字・部品）、`architecture.md` 7章・8章

## 0. この文書について

### 0.1 範囲

v0.1 の画面。利用者は「仕様JSON（または同梱サンプル）を開く → 値を確かめて直す → 実行する → スコープで波形を読む」ができる。
AI、設計書の取り込み、目標値とゲイン最適化、レポートは含まない。後のリリースで入る場所は 13章に書いた。

### 0.2 読み方

- 各章は同じ6項目で書く: **用事**、**要素と配置**、**状態**（読み込み中・空・正常・エラー）、**操作**、**文言**（日英）、**受け入れ基準**。
- 色、文字の大きさ、部品の状態ごとの見え方は `design-system.md` に従う。この文書では値を繰り返さない。
- 文言の表の「キー」は辞書のキー。`{…}` は差し込む値。表に無い文字列を画面に出さない。
- 受け入れ基準は `AC-章-連番`。verifier と ux-designer はこの番号で合否を付ける。
- 「Ctrl」は macOS では「⌘」に読み替える（画面の表示も切り替える）。

### 0.3 全部の画面に共通の決まり

1. **4つの状態。** 読み込み中＝待っている。空＝まだ中身が無い（次にすることを1つ示す）。正常。エラー＝何が起きたかと、どう直すかを対で示す。
2. **反応の速さ。** 操作から画面が変わるまで 100 ms 以内。それより長くかかる処理は、200 ms たっても終わらないときに待ちの表示を出す（`design-system.md` 9章）。
3. **エラーの書き方。** 1文目に何が起きたか（場所つき: 何行目、どの項目）、2文目にどう直すか。プログラムの内部の文（例外の文面）は主文に出さず、「詳細」を開いたときだけ見せる。
4. **押せない操作には理由を添える。** 使えないボタンのそばに、なぜ使えないか、何をすれば使えるかを出す。
5. **キーボード。** この文書の操作はすべてキーボードでできる。フォーカスの位置は常に見える。一覧は付録C。
6. **測り方。** 時間の基準は、Chromium の最新安定版、ウィンドウ 1280×720、画素密度 1 で、同じ操作を30回以上くり返した95パーセンタイル。見た目の基準は 1280×720 と 1920×1080、明・暗、日本語・英語の全組み合わせ（8通り）で確かめる。

## 1. 全体の枠（S0）

### 1.1 用事

どの段階でも同じ場所に同じものがあり、開く・確かめる・実行する・読むを、画面を切り替えずに行き来できること。

### 1.2 要素と配置

1つの画面で完結する。ページの切り替えも、縦に流れるスクロールも無い（各領域の中だけがスクロールする）。

```
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│ ①        ②                           ③                        ④                     ⑤        │ ヘッダー 48（1行）
├─────────────────────────────┬─┬──────────────────────────────────────────────────────────────┤
│ 仕様パネル（5章）            │↔│ 回路図（6章）                                             [ˆ] │ 既定 180
│  幅 既定 360（300〜560）     │ ├══════════════════════════════════════════════════════════════┤ ↕ 仕切り
│  たためる                    │ │ スコープ（8章）                                               │ 残り全部
│                             │ │   道具の列 ／ 波形 ／ 信号と読み取り                           │
├─────────────────────────────┴─┴──────────────────────────────────────────────────────────────┤
│ お知らせ（9章）  ✕ エラー 0 ・ ◌ 不足 0 ・ ⚠ 注意 1 │ 古い結果: 仕様を変更しました…        [ˆ] │ 32
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```

ヘッダーは1行。左から順に並べ、③と④の間の余白が伸び縮みする（④と⑤は右に寄る）。

```
① circuit-sim │ ② rlc_series.json ●未保存 ・ 直列RLC │ ③ [開く][サンプル▾][保存]   ‥余白‥   ④ [▶ 実行] 実行 3 完了 ・ 0.12 s ・ 3,183 ステップ │ ⑤ [日本語|English] [明|暗]
```

| 部分 | 中身 | 寸法 |
|---|---|---|
| ヘッダー | ① アプリ名 ② 開いている仕様 ③ ファイルの操作 ④ 実行と実行の状態（7章） ⑤ 言語とテーマ（10章） | 高さ 48 |
| ② 開いている仕様 | ファイル名（等幅。長いときは中ほどを省略）、未保存の印、テンプレートの表示名 | 最大幅 320 |
| 仕様パネル | 5章 | 幅 既定 360、最小 300、最大 560。たたむと幅 32 の縦の帯（「仕様」と不足・エラーの件数） |
| 回路図 | 6章 | 高さ 既定 180（図が原寸で収まる高さ）、最小 140、最大は中央の列の高さの 50%。見出しの行を持たない（名前とたたむボタンは図の面の隅に置く）。たたむと高さ 28 の帯だけ |
| スコープ | 8章 | 中央の列の残り全部。最小の高さ 280 |
| お知らせ | 9章 | たたむと 32。開くと中身に合わせて最大でウィンドウの高さの 40% |

- 対応するウィンドウの大きさは 1280×720 以上。それより小さいときは、配置を崩さずにページ全体をスクロールさせる。
- 仕切りの位置と、たたんだ状態は、ブラウザに覚えさせる（次に開いたときも同じ）。
- v0.1 には右の列（目標値と結果）と、段階の表示（①〜⑤）は無い。使えないものを薄く置いておくことはしない（13章）。

**フォーカスの順番（Tab）。** ヘッダー（開く → サンプル → 保存 → 実行 → 言語 → テーマ）→ 仕様パネル → 回路図 → スコープの道具の列 → 波形 → 信号と読み取りの表 → お知らせ。
仕様の表、回路図、道具の列、波形、読み取り表は、それぞれ Tab で止まるのは1回で、中は矢印キーで動く。

### 1.3 状態

| 状態 | 見え方 |
|---|---|
| 読み込み中（起動してアプリ本体につながるまで） | ヘッダーだけを出し、中央に「アプリ本体に接続しています…」。200 ms 以内につながれば何も出さない |
| 空（仕様を開いていない） | ヘッダー ＋ 起動直後の画面（3章）。仕様パネル・回路図・スコープ・お知らせの枠は出さない |
| 正常（仕様を開いている） | 上の配置図 |
| エラー（アプリ本体につながらない） | ヘッダーの上に、幅いっぱいの帯（エラーの色の記号と言葉）。画面の中身は最後の状態のまま残し、波形と値は読める。開く・サンプル・保存・実行・値の編集は使えなくなる。2秒ごとに自動でつなぎ直す |

**つなぎ直した後。**

- アプリ本体が同じまま（通信が切れただけ）: 帯が消え、そのまま続けられる。
- アプリ本体が起動し直されていた: 画面が持っている仕様（編集した内容を含む）を送り直して続ける。結果は消えているので、スコープは「空」に戻り、お知らせに N-CONN-RESTART を出す。

**ブラウザの再読み込み。** アプリ本体が動いている間は、再読み込みしても、開いている仕様、編集した内容、今回の結果、比較対象の結果が元に戻る。表示範囲、カーソル、信号の選び方は既定に戻ってよい。F5 を「実行」のつもりで押す人がいるので、再読み込みで作業を失わせない。

### 1.4 操作

| 操作 | 結果 |
|---|---|
| 仕切りをドラッグ（またはフォーカスして矢印キー） | 幅・高さが変わる。ダブルクリックで既定に戻る |
| 仕様パネル・回路図・お知らせの見出しの山形のボタン | たたむ・開く |
| Ctrl+O | ファイルを選ぶ画面を開く（4章） |
| Ctrl+S | 仕様を保存する（5.4） |
| Ctrl+Enter | 実行する（7章）。入力欄を編集中でも効く（編集を確定してから実行） |
| Ctrl+.（ピリオド） | 計算を中断する（7章） |
| ウィンドウのどこかにファイルをドロップ | 開く（4章） |

1文字のキー（A、B、C、F など）は、波形にフォーカスがあるときだけ効く（8章）。入力欄にフォーカスがある間、1文字のキーの操作は起きない。

## 2. 数値の表記と入力（共通の決まり）

すべての画面の数値がこの章に従う。

### 2.1 表示

**形。** `数値` ＋ 改行されない空白 ＋ `接頭辞` ＋ `単位`。例: `47 µH`、`100 kHz`、`-1.5 A`、`0 V`。

- 接頭辞は f（10⁻¹⁵）、p、n、µ、m、なし、k、M、G（10⁹）。数値の部分が 1 以上 1000 未満になるものを選ぶ。0 は接頭辞なし。この範囲に収まらない値は、基本単位で指数表記にする（`1.5e-18 F`）。
- 単位の無い量（デューティなど）は数値だけ。
- 負の符号は `-`（U+002D）。小数点は `.`。桁区切りは、整数の個数（ステップ数、点数）にだけコンマを使う（`3,183`）。
- 有限でない値（計算の失敗）は `—` を出し、お知らせを出す。

**桁数。** 場所ごとに決める。丸めたことが分かるようにする。

| 場所 | 桁数 |
|---|---|
| 仕様パネルの値 | 有効数字9桁までで、元の値に戻せる最も短い表記。末尾の 0 は書かない（`47 µH`、`3.18309886 mH`） |
| 編集を始めたときの入力欄の中 | 丸めない（元の値に戻せる最も短い表記） |
| 回路図の値 | 有効数字4桁まで。丸めたときは前に `≈` を付ける（`≈3.183 mH`） |
| スコープの読み取り（A、B、Δ、時刻） | 有効数字6桁で固定。末尾の 0 も書く（`12.0000 V`）。Δ は丸める前の値どうしで計算する |
| スコープのポインタの列 | 有効数字4桁。1列に複数のサンプルがあるときは範囲（`11.98〜12.02 V`） |
| 軸の目盛り | 隣の目盛りと区別できる最小の桁数 |
| 所要時間（計算にかかった実際の時間） | 単位は s。有効数字2桁（`0.12 s`、`3.4 s`、`72 s`） |

**JSON の単位と画面の単位。**

| 仕様JSONの `unit` | 画面の単位 | JSON で同じ意味として受け付ける書き方 |
|---|---|---|
| `V` | V | — |
| `A` | A | — |
| `ohm` | Ω | `Ohm`、`OHM`、`Ω`、`Ω`（U+2126） |
| `H` | H | — |
| `F` | F | — |
| `s` | s | — |
| `Hz` | Hz | `hz`、`HZ` |
| `1/V` | 1/V | — |
| `1/(V·s)` | 1/(V·s) | `1/(V*s)`、`1/(V s)` |
| `s/V` | s/V | — |
| `1`（無次元） | なし | — |
| `""`（単位なし） | なし | — |

**接頭辞を付けない単位。** 制御のゲインの単位（`1/V`、`1/(V·s)`、`s/V`）と、単位の無い量（デューティなど）には、表示でも JSON でも接頭辞を付けない（`m/V` はメートル毎ボルトとも読めるため）。数値の桁数の決まりは同じで、絶対値が 1e-3 以上 1e6 未満は小数（`0.0117 1/V`、`147 1/(V·s)`、`0.9`）、その外は指数表記（`2.74e-6 s/V`）にする。入力では、数値の後ろの接頭辞を倍率として読み、解釈の表示に結果を出す（`11.7m` → `= 0.0117 1/V`）。無次元の項目は `%` も受け付けて 1/100 にする（入力の `90%` → `0.9`。JSON の `{"value": 90, "unit": "%"}` は換算として読み、N-UNIT-CONVERTED に出す）。

**JSON の単位の読み方。** 単位を読み飛ばさない。`{"value": 1, "unit": "mH"}` を 1 H として扱うことが、どの経路でも起きないようにする。

| JSON の `unit` | 画面での扱い |
|---|---|
| その項目の単位と同じ（上の表の別の書き方を含む） | そのまま読む |
| その項目の単位に接頭辞が付いたもの（`mH`、`uF`、`kHz`、`kohm`。接頭辞の読み方は 2.2 と同じで、大文字と小文字を区別する） | 基本単位に換算して読む（換算は厳密で、推測ではない）。開いた後、換算した値をお知らせにまとめて出す（N-UNIT-CONVERTED）。行の値は、いつもどおり接頭辞つきで出る（`1 mH`） |
| 次元が違う、または読めない（H の項目に `F`、`V` の項目に `volt` など） | 値を読まない。その行を「エラー」にし、ファイルに書かれていた値と単位をそのまま見せて（`1 F`）、正しい単位で入力し直してもらう（N-UNIT-WRONG）。直すまで実行できない |

保存するときは、基本単位と上の表の左の列の書き方に直す（`value: 1e-3, unit: "H"`）。換算と誤りの判定そのものは計算エンジンが行い、画面はその結果を見せる（12章 D3）。画面とコマンドラインで扱いが食い違わないようにするため。

### 2.2 入力

表示と同じ書き方で入力できる。違いは、単位と接頭辞の後ろを省けることだけ。

```
[符号] 数値 [e 指数] [空白] [接頭辞] [単位]
```

| 決まり | 内容 |
|---|---|
| 数値 | 10進。小数点は `.`。`.5` と `5.` も可。指数は `e` か `E`（`4.7e-5`） |
| 接頭辞 | `f` `p` `n` `µ` `m` `k` `M` `G`。**大文字と小文字を区別する（`m` はミリ、`M` はメガ）** |
| 接頭辞の別の書き方 | マイクロは `u`、`μ` でもよい。キロは `K` でもよい。メガは `meg`（大文字小文字を問わない）でもよい |
| 単位 | 省ける。書くなら、その欄の単位と同じであること。1文字の単位（V、A、H、F、s）は大文字と小文字を区別する。`ohm` と `Hz` は区別しない |
| 空白 | 数値・接頭辞・単位の間の空白は、あっても無くてもよい |
| 全角 | 全角の数字・英字・記号（`４７ｕ`、`－`、`．`）は半角に直して読む。日本語入力がオンのままでも入力できる |
| 空欄 | 値なし。必須の項目なら「不足」になり、「自動」のある項目なら自動に戻る |
| 範囲 | 項目ごとの範囲（付録A）。v0.1 では「0 より大きい」「0 以上」「有限」と、デューティの「0 以上 1 以下」 |

**読めないもの（エラーにして、直し方を出す）。**

| 入力 | 理由 |
|---|---|
| `1,000`、`4,7` | コンマは桁区切りか小数点か決められない |
| `4k7`、`6K34` | 接頭辞を小数点の代わりにする書き方は受け付けない |
| `47uF`（単位が H の欄） | 単位が違う |
| `47U`、`5v`、`2a` | 接頭辞・単位の大文字小文字が違う |
| `1e`、`abc`、`inf`、`nan` | 数値でない、有限でない |

**解釈をその場で見せる。** 入力の途中から、欄の下の小さな面に「どう読んだか」を出し続ける。接頭辞があるときは基本単位での値も添える。

```
入力: 1M          → = 1 MΩ（1e6 Ω）
入力: 47u         → = 47 µH（4.7e-5 H）
入力: 0.047m      → = 47 µH（4.7e-5 H）
入力: 10          → = 10 V
```

SPICE に慣れた人は `1M` をミリのつもりで打つ（SPICE の `M` はミリ、メガは `MEG`）。この画面は表示と同じ SI の書き方に合わせ、取り違えには次の2段で気づけるようにする。

1. **打っている間**: 「解釈」の表示。開いたときの値（「変更」の印と同じ基準。5.3）の 1000 倍以上、または 1/1000 以下になる入力には、注意の記号つきで倍率を添える。

   ```
   入力: 1M（変更前 1 Ω）   → = 1 MΩ（1e6 Ω）  ⚠ 変更前の 1,000,000 倍
   ```

   倍率は有効数字3桁に丸め、桁区切りを付ける。丸めたときだけ前に `≈` を付ける（1234 倍は「≈1,230 倍」、ちょうど 1000 倍は「1,000 倍」）。

2. **確定した後**: 同じ条件のとき、お知らせに「注意」を1件出す（N-BIG-CHANGE）。止めはしない（実行できる）。値が条件から外れるか、お知らせを閉じると消える。

桁の取り違え（m と M、µ と m、k と M）は 1000 倍の単位で起きるので、しきい値を 1000 倍に置いた。開いたときに値が無かった（不足だった）項目と、値が 0 だった項目には出さない。

**例（単位が H の欄）。** 実装のテストに使う。

|---|---|

| `1m` | 1 mH |
| `1M`、`1meg`、`1MEG`、`1e3k` | 1 MH（解釈に `1e6 H` と出る） |
| `2.2K`、`2.2k` | 2.2 kH |
| `+5`、`5.`、`5 H` | 5 H |
| `-5`、`0` | エラー: 0 より大きい値が必要 |
| （空欄） | 不足 |
| `47uF` | エラー: 単位が違う |
| `47U`、`1h` | エラー: 読めない |
| `1,000`、`4k7` | エラー: それぞれの直し方を出す |

## 4. 仕様JSONを開く（S2）

### 4.1 用事

手元の仕様JSONを開いて、中身が画面に並ぶこと。開けなかったときは、ファイルのどこを直せばよいかが分かること。

### 4.2 要素と配置

開く入口は3つ。どれも同じ処理に入る。

| 入口 | 場所 |
|---|---|
| ファイルを選ぶ | 起動直後の画面の「ファイルを選ぶ…」、ヘッダーの「開く」、Ctrl+O |
| ドロップ | ウィンドウ全体（起動直後でも、仕様を開いた後でも）。ドラッグ中は、ウィンドウ全体に `bg-app` の不透明度 80% の覆いと、破線の枠、「ここにドロップして開く」を出す |
| サンプル | 起動直後の画面の一覧、ヘッダーの「サンプル▾」のメニュー（3つのサンプルの名前） |

**開く処理の順番。** 上から確かめ、最初に引っかかった所で止めて、その理由を出す。

1. 1つのファイルか（複数なら N-OPEN-MULTI）
2. 拡張子が `.json` か（違えば N-OPEN-TYPE）
3. 10 MB 以下か（超えたら N-OPEN-SIZE。仕様JSONは数 KB なので、別のファイルを誤って入れたときの安全弁）
4. UTF-8 として読めるか（先頭の BOM は許す。読めなければ N-OPEN-ENCODING）
5. JSON として読めるか（N-OPEN-SYNTAX。行と文字の位置を出す）
6. `schema_version` がこのアプリの読める版か（N-OPEN-VERSION）
7. 仕様の形に合っているか（必要な欄、知らない欄、型。N-OPEN-SCHEMA。JSON の中の位置を最大5件）
8. `template` がこのアプリにあるか（N-OPEN-TEMPLATE。使えるテンプレートを並べる）

**止めずに開くもの。** 開いてから画面の中で直せるので、開く。

| ファイルの中身 | 開いた後の見え方 |
|---|---|
| 値が `null`、またはテンプレートに必要な項目が `plant` に無い | その行が「不足」（5章）。お知らせに N-MISSING |
| 値が範囲の外（0 以下など） | その行が「エラー」。お知らせに N-INVALID |
| 単位に接頭辞が付いている（`mH`、`uF`、`kHz`） | 基本単位に換算して読む（2.1）。お知らせに N-UNIT-CONVERTED（何をどう換算したかを全部並べる） |
| 単位の次元が違う、読めない | その行が「エラー」。ファイルに書かれていた値と単位を見せる（2.1）。お知らせに N-UNIT-WRONG |
| テンプレートが使わない項目が `plant` にある | 表には出さない。お知らせに N-UNUSED（保存するときは、そのまま残す） |
| `targets` に値がある | 仕様パネルの下に1行（5.2）。保存するときは、そのまま残す |
| `missing` の一覧が、実際に値の無い項目と食い違う | 画面は実際の値から判断する。保存するときに `missing` を書き直す |

**保存していない変更があるとき。** 別の仕様を開こうとしたら、開く前に確認のダイアログを出す。

```
┌ 保存していない変更があります ────────────────────────────┐
│ 別の仕様を開くと、いまの変更は失われます。                │
│                                                          │
│              [保存してから開く] [保存せずに開く] [やめる]  │
└──────────────────────────────────────────────────────────┘
```

最初のフォーカスは「やめる」。Esc は「やめる」。

### 4.3 状態

| 状態 | 見え方 |
|---|---|
| 読み込み中 | 200 ms たっても終わらないとき、起動直後の画面なら枠の中に、仕様を開いた後ならヘッダーの②に「読み込んでいます…（ファイル名）」 |

|---|---|---|
| `source` に文字列がある（`p.3 表2`、`仕様!B4` など） | その文字列のまま。入りきらなければ省略してツールチップ | `text-secondary` |
| `source` が `手入力` または `manual`、または画面で値を変えた | 手入力 / Manual | `text-secondary` |
| テンプレートの既定値を使っている（省略できる項目で値が無い） | 既定値 / Default | `text-secondary` |
| 計算の設定で、回路定数から自動で決めた | 自動 / Auto | `text-secondary` |
| `source` が `null` で、値はある | 記載なし / Not given | `text-muted` |
| 値が無い（不足） | — | `text-muted` |

画面で値を変えると、保存する JSON の `source` には `手入力` と書く（表示の言語によらない。4章の表と付録Aの決まり）。

**群。** テンプレートの表示定義（付録A）の順に並べる。並べ替えない（不足を上に集めたりしない。行の位置が変わると見失うため）。

| 群 | 中身 | v0.1 で出るテンプレート |
|---|---|---|
| 回路 | `plant` の項目 | 全部 |
| 制御 | `control` の項目（周波数、指令値、ゲイン、デューティの上下限）。仕様の版 0.2 から `plant` と同じ形（値・単位・出どころ。D-039） | 降圧コンバータ |
| 計算の設定 | モデル `fidelity`（スイッチを含むテンプレートだけ）、終了時刻 `t_end`、時間刻み `h`、ステップ数（表示だけ） | 全部（モデルの行は降圧コンバータだけ） |

`simulation` の値（`fidelity`、`t_end`、`h`）は JSON に出どころの欄を持たない。ファイルに書かれていれば出どころは「記載なし」、無ければ「既定値」または「自動」、画面で変えれば「手入力」。
仕様の版 0.1 のファイルの `control` の数値（単位も出どころも無い）は、付録Aの単位とみなして読み、出どころを「記載なし」にして、N-OPEN-LEGACY を出す（付録B.3）。

**計算の設定の行。**

- 値が仕様に無いときは、テンプレートが回路定数から決めた値を出し、出どころを「自動」にする。回路の値が変わるたびに計算し直す。
- 回路の値に不足やエラーがあって決められないときは、値を `—` にし、項目のツールチップではなく行の中（出どころの列）に「未定」と出す。
- 値を入力すると固定になる（出どころは「手入力」）。空欄にして確定すると自動に戻る。
- ステップ数は 終了時刻 ÷ 時間刻み。編集できない。終了時刻か時間刻みを編集している間は、解釈の表示に、その入力でのステップ数も出す（`= 20 ms ・ ステップ数 6,366`）。
- 言葉の決まり: `t_end` は「終了時刻」（計算する時間の長さ。0 から始まる）、`h` は「時間刻み」。計算にかかった実際の時間は「所要時間」と呼ぶ。「計算時間」は両方に取れるので、画面で使わない。

**モデルの行（スイッチング / 平均）。** スイッチを含むテンプレート（v0.1 では降圧コンバータ）だけに、計算の設定の群の先頭に出す。

```
│ 計算の設定                                        │
│ fidelity モデル          [スイッチング ▾]  既定値    │
│ t_end   終了時刻           8.62 ms    自動          │
│ h       時間刻み            50 ns     自動          │
│         ステップ数         172,400                  │
```

- 記号 `fidelity`、項目「モデル」。値の欄は選択欄（`design-system.md` 6.10）で、選択肢は「スイッチング」「平均」。2択の切り替えにしないのは、3つ目の「理想」（CLAUDE.md 決まり6）を足せるようにするため。
- 仕様に無いときはテンプレートの既定（降圧コンバータはスイッチング）を出し、出どころを「既定値」にする。
- 選び替えは、ほかの値の変更と同じに扱う。「変更」の印と「元に戻す」が付く。時間刻みの自動の値とステップ数がその場で変わる（降圧コンバータ: スイッチングはスイッチング周期の 1/200、平均は 1/10）。結果があればスコープは「古い結果」になり、違いに `fidelity スイッチング → 平均` と出る。回路図はレグの描き方が替わる（付録A.4）。
- この行は「次に計算するモデル」。いま見ている波形がどちらのモデルのものかは、スコープの結果の説明に常に出す（8.2 ①）。仕様パネルをスクロールしてこの行が見えなくても、波形のそばで分かる。
- 平均モデルを選んだこと自体は「注意」にしない（結果の誤りではなくモデルの性質で、毎回出る注意は読まれなくなる）。違いは、結果の説明のモデル名、項目の説明（ツールチップ）、平均モデルに無い信号の表の行（8.2 ⑤）で示す。

**ステップ数の上限。** 計算エンジンは、1回の計算のステップ数に上限を持つ（値はエンジンが決め、画面は受け取って見せる）。自動で決めた値でも、速い成分と遅い成分の離れた回路では上限を超えることがある。超えたら、実行する前に分かるようにする。

```
│ 計算の設定                                        │
│ t_end   終了時刻           2 s        自動          │
│ h       時間刻み           1 ns       自動          │
│ ✕       ステップ数         2,000,000,000  上限 50,000,000 を超えています │
```

（上限の数字は例。実際の値は計算エンジンから受け取る。）

- ステップ数の行が「エラー」の見え方になり、上限を添える。実行できない（7章の「実行できない」に理由が出る）。
- お知らせに N-STEPS-LIMIT。直し方に、**そのまま打てる値**を入れる: 時間刻みを変えないなら終了時刻はいくつまで、終了時刻を変えないなら時間刻みはいくつ以上。「終了時刻へ」「時間刻みへ」の2つのリンクから、その行の編集に入る。
- 終了時刻か時間刻みを編集している間、解釈の表示のステップ数が上限を超えていれば、エラーの色で「上限を超えます」と出る。打ちながら、収まる値を探せる。
- 上限の中に収まれば、行は通常に戻り、お知らせも消える。

**時間刻みが粗いとき。** 時間刻みが回路の速い時定数に対して粗いと、計算は終わるが波形が正しくないことがある。計算エンジンがそう判定したら、止めずに「注意」で知らせる。

- 実行の前に判定できるとき: 時間刻みの行が「注意」の見え方になり（5.3）、お知らせに N-STEP-COARSE。実行はできる。
- 実行の結果に付いてきたとき: その結果を見ているあいだ、スコープの上の帯（8.2 ②）とヘッダーの実行の状態に「注意」が出て、お知らせに N-RUN-NOTE-STEP。「時間刻みへ」のリンクから編集に入る。エンジンが目安の値を返すなら、直し方に入れる。

**その他。**

- 見出し行の右のボタンでパネルをたたむ。たたんだ帯には「仕様」と、不足・エラーの件数の札を出す（たたんでいても不足が隠れない）。
- `targets` に値がある仕様では、表の下に1行「目標値 {n} 件は、この版では使いません。」を出す（保存すると、そのまま残る）。

### 5.3 状態

**パネルの状態。**

| 状態 | 見え方 |
|---|---|
| 読み込み中 | 見出し行だけを出し、表の位置に「仕様を読み込んでいます…」（200 ms たっても終わらないとき） |
| 空 | 仕様を開いていないときは、パネルそのものを出さない（3章） |
| 正常 | 上の配置図 |
| エラー（テンプレートの定義が取れない） | 表の位置に「テンプレートの情報を読み込めませんでした。」と「もう一度」 |

**行の状態。** 見え方は `design-system.md` 6.3・6.4。

| 行の状態 | 条件 | 見え方 | 実行 |
|---|---|---|---|
| 通常 | 値があり、開いたときから変えていない | — | できる |
| 変更 | 値が、開いたときのファイルの値と違う | 値の左に点。出どころが「手入力」。「元に戻す」のボタンが出る。点のツールチップに「変更前: 1 Ω（出どころ: p.3 表2）」 | できる |
| 不足 | 必須の項目に値が無い | 左端に不足の色の帯。値の欄が破線の枠で、中に記号と「不足」 | できない |
| 既定値 | 省略できる項目に値が無く、テンプレートの既定値を使う | 値を `text-secondary` で出し、出どころが「既定値」 | できる |
| 編集中 | 値の欄を編集している | 入力欄 ＋ 下に解釈の表示（2.2） | — |
| エラー | 確定しようとした入力が読めない、または範囲の外。ファイルの単位が違う（2.1）。ステップ数が上限を超えている | 左端にエラーの色の帯。入力欄に打った文字（ファイルから来たものは、書かれていた値と単位）をそのまま残し、下に何が違うかと直し方 | できない |
| 注意 | 値は受け付けたが、確かめてほしいことがある（時間刻みが粗い） | 左端に注意の色の帯、値の左に注意の記号。記号にフォーカスするかポインタを乗せると理由。同じ内容がお知らせにある | できる |

- 「変更」の印は、**開いたときのファイル**との違いを示す。保存しても消えない（どの値を自分で変えたかが、最後まで分かる）。ヘッダーの「未保存」は、**最後に保存した後**に変更があることを示す。この2つは別のもの。
- 打った値が開いたときの値と同じに戻ったら、「変更」の印は消え、出どころも元に戻る。
- エラーの行は、打った文字を捨てない。フォーカスが外れても、エラーのまま残る。以前の値に黙って戻すことはしない（戻ったことに気づかないまま実行してしまうため）。

### 5.4 操作

| 操作 | 結果 |
|---|---|
| 値を押す。行にフォーカスして Enter か F2 | 編集を始める。入力欄に今の値（丸めない表記）が入り、全部選ばれている |
| 行にフォーカスして、数字・`.`・`-`・`+` を打つ | 打った文字で編集を始める（今の値を置き換える） |
| モデルの行で、値を押す・Enter・F2 | 選択欄を開く。↑ / ↓ で選び、Enter で確定、Esc で取り消し。数字を打っても編集は始まらない。Tab ／ Shift+Tab は、ほかの行と同じく次／前の行の値へ |
| 編集中に Enter | 確定。読めれば値が変わり、フォーカスは同じ行に残る。読めなければエラーの状態になり、入力欄に留まる |
| 編集中に Tab ／ Shift+Tab | 確定して、次の行／前の行の値に移る（続けて入力できる） |
| 編集中に Esc | 取り消し。編集を始める前の値と状態に戻る |
| 編集中に Ctrl+Enter | 確定してから実行（7章）。読めなければ実行せず、エラーの状態で留まる |
| 編集中に欄の外を押す | 確定（Enter と同じ） |
| 上下の矢印キー（編集していないとき） | 行の間を移る |
| 左右の矢印キー（編集していないとき） | 同じ行の「値」と「元に戻す」の間を移る |
| 「元に戻す」を押す | 開いたときの値と出どころに戻る |
| 行にポインタを乗せる、フォーカスする | 回路図の対応する素子が強調される（6章） |
| ヘッダーの「保存」、Ctrl+S | 今の仕様を JSON でダウンロードする。ファイル名は開いたファイルと同じ（サンプルはテンプレート名 `.json`）。不足やエラーがあっても保存できる（不足は `null` で書き、エラーの行は確定済みの最後の値を書く。エラーの行があるときは、保存の前に N-SAVE-INVALID を出す） |

値が確定したら、次のものが 100 ms 以内に変わる: その行、回路図の値、計算の設定の自動の値とステップ数、お知らせ、実行ボタンの状態、スコープの「古い結果」の表示（8章）。

**取り消し。** v0.1 で戻せるのは行ごと（「元に戻す」で開いたときの値へ）。編集中の入力欄の中では、ブラウザの取り消し（Ctrl+Z）が効く。確定した変更を順にさかのぼる取り消しは v0.1 に入れない（14章 #13）。

## 6. 回路図（S4）

### 6.1 用事

いま計算しようとしている回路が、自分の考えている回路と同じ形・同じ値かを、図でひと目で確かめること。波形の名前（`v(out)`、`i(L1)`）が、回路のどこの、どちら向きの量かが分かること。

### 6.2 要素と配置

テンプレートごとに決まった図に、いまの値を重ねて出す。図は描き替えられない（回路図エディタではない）。

```
┌────────────────────────────────────────────────────────────────────┐
│ 回路図                                                         [ˆ] │  ← 名前とたたむボタンは図の面の隅（行を取らない）
│      [v(in)]            R1          a          L1    ▸[i(L1)]      │
│        │   in ●───────▭▭▭▭──────●──────⌒⌒⌒⌒───────●──[━ v(out)]  │
│        │              2 Ω                 1 mH        │  out       │
│      ( V1 )                                         ══╪══ C1       │
│   0 → 10 V                                            │   不足     │
│      t = 0                                            │            │
│        ▾[i(V1)]                                       │            │
│        └──────────────────────┬───────────────────────┘            │
│                              ─┴─ 0                                 │
└────────────────────────────────────────────────────────────────────┘

図に出すもの（描き方は `design-system.md` 8章、テンプレートごとの配置は付録A）:

| 要素 | 中身 |
|---|---|
| 素子 | 記号、名前（`R1`）、値（`2 Ω`。2章の「回路図の値」の桁数） |
| 電源 | 記号、名前、**波形の種類と値**（`0 → 10 V`、`t = 0`。直流なら `直流 24 V`）。何を入力しているかが図だけで分かるようにする |
| 節点 | 名前（`in`、`a`、`out`）、基準点（`0`） |
| 測定点の印 | スコープに出せる信号ごとに1つ。電圧は節点から引き出した枠、電流は配線の上の矢じりと枠。矢じりの向きが、その電流の正の向き |
| 制御の部分（降圧コンバータ） | 比較（Σ）、PID、PWM を箱で描き、信号の流れを破線の矢印で示す。値（指令値、ゲイン、周波数、デューティの上下限）を箱のそばに出す。電力の部分とは、信号名の札（`v(out)`、`q1`、`q2`）でつなぐ。同じ名前どうしがつながっている、という回路図の慣習に従い、長い線で図を横切らない |
| 段差（降圧コンバータ） | 負荷の段差は R1 の値の下に、指令の段差は指令値の下に、電源の段差と同じ書き方で出す（`→ 3 Ω`、`t = 5 ms`）。段差を作るためにエンジンが足す素子（R2、S3）は描かない（利用者が入れた値ではないため） |
| モデルによる描き替え（降圧コンバータ） | モデルが「平均」のとき、レグ（S1・S2）を電源 Vleg（`duty × Vin`）に描き替え、平均モデルに無い信号の測定点を出さない（付録A.4）。図は仕様パネルのモデルの値に従う（次に計算する回路を見せる） |

- 図は領域の中央に、縦横比を保って収める。既定の高さ（180）で、RCローパスと直列RLCの図は原寸（文字 12〜13px）で出る。領域は高さ 140 より小さくできない（仕切りの最小。このとき図は約 0.8 倍）。
- 図の倍率は 0.75 倍（文字 9px）より小さくしない。降圧コンバータの図（幅 960）が領域の幅に収まらないときは 0.75 倍で描き、領域の中を横にスクロールできるようにする（スクロールの位置は、別の仕様を開くと左端に戻る）。RCローパスと直列RLCの図は、対応するウィンドウの大きさでスクロールにならない。
- 見出しの行を持たない。左上の隅に「回路図」、右上の隅にたたむボタンを、図の面の上に置く（波形に高さを回すため）。たたむと、高さ 28 の帯に「回路図」と開くボタンだけが残る。
- 図の中の値は編集できない。編集は仕様パネルだけで行う（同じ値を直す場所を2つ作らない）。

### 6.4 操作

| 操作 | 結果 |
|---|---|
| 素子（記号・名前・値のどこでも）にポインタを乗せる | その素子と、仕様パネルの対応する行が強調される |
| 素子を押す | 仕様パネルの対応する行が選ばれ、見える位置までスクロールする。パネルがたたまれていたら開く |

## 7. 実行（S5）

### 7.1 用事

いまの値で計算を始め、どこまで進んだかを見て、要らなければ止めること。終わったのか、失敗したのか、なぜ始められないのかが、すぐ分かること。

### 7.2 要素と配置

ヘッダーの④。ボタン1つと、その右の状態の表示。

```
実行できる        [▶ 実行]   未実行
実行できない      [▶ 実行]   不足 2 件 ・ 入力エラー 1 件          ← 件数は押せる（その行へ移る）
実行できない      [▶ 実行]   ステップ数が上限を超えています        ← 押すとステップ数の行へ（5.2）
計算中（割合あり） [■ 中断]   ▰▰▰▰▱▱▱▱ 42% ・ 1.2 s
計算中（割合なし） [■ 中断]   ▱▰▰▱▱▱▱▱ 計算中 ・ 1.2 s
中断している      [■ 中断]   中断しています…
完了             [▶ 実行]   実行 3 完了 ・ 0.12 s ・ 3,183 ステップ
完了（注意あり）  [▶ 実行]   実行 3 完了 ・ 0.12 s ・ 3,183 ステップ  [⚠ 注意 1]   ← 計算からの注意。押すとお知らせへ
完了（古い）      [▶ 実行]   実行 3 完了 ・ 0.12 s ・ 3,183 ステップ  [⚠ 古い結果]
中断した          [▶ 実行]   実行 4 を中断しました
失敗             [▶ 実行]   実行 4 失敗 ・ 理由を見る              ← 「理由を見る」は押せる
```

- ボタンは幅を固定する（「実行」と「中断」で幅が変わらない。96px）。「実行」は主ボタン、「中断」は副ボタン。
- 状態の表示は1行。幅は最大 360。入りきらないときはステップ数から先に省く。
- 実行の番号は、仕様を開いてから数えた通し番号。完了・中断・失敗のどれでも1つ進む。別の仕様を開くと 1 に戻る。
- 完了の表示の時間は、計算にかかった実際の時間（所要時間）。ポインタを乗せると、「所要時間」という名前と、終わった時刻（24時間表記）をツールチップに出す。

### 7.3 状態

| 状態 | 条件 | ボタン | 状態の表示 |
|---|---|---|---|
| 仕様なし | 仕様を開いていない | 実行（使えない） | 仕様を開いてください |
| 実行できる | 不足もエラーも無い | 実行 | まだ実行していなければ「未実行」。していれば直前の実行の結果 |
| 実行できない | 不足かエラーの行がある。ステップ数が上限を超えている | 実行（使えない） | 件数、または「ステップ数が上限を超えています」。押すと最初のその行へ移る |
| 計算中 | 計算が始まってから終わるまで | 中断 | 進み具合。**始まって 200 ms たってから出す**（それまではボタンだけが「中断」に変わる）。割合が分かれば棒と割合、分からなければ行き来する印。どちらも経過時間を出す |
| 中断している | 中断を押してから止まるまで | 中断（使えない） | 中断しています… |
| 完了 | 計算が終わった | 実行 | 番号、所要時間、ステップ数。計算からの注意があれば、件数の札（押すとお知らせのその行へ） |
| 中断した | 利用者が止めた | 実行 | 番号と「中断しました」 |
| 失敗 | 計算が終わらなかった | 実行 | 番号と「失敗」、「理由を見る」（お知らせを開いて、その行へ移る） |

4つの状態との対応: 読み込み中＝計算中・中断している、空＝仕様なし・未実行、正常＝実行できる・完了、エラー＝実行できない・失敗。

**決まり。**

- **結果は、計算を始めたときの仕様の写しを持つ。** 「古い結果」の判定、古い結果の「違い」、比較の「違い」は、この写しと、いまの仕様（または別の結果の写し）を比べて出す。
- **途中の結果は見せない。** 中断・失敗したときは、その実行の波形を捨てる。スコープには、直前に完了した結果があればそれが残る（仕様が変わっていれば「古い結果」になる）。途中までの波形を完了した結果と取り違えさせない。
- **計算中も画面は使える。** 値の編集、波形の拡大縮小、カーソル、言語とテーマの切り替えができる。計算中に値を変えたら、終わった結果は「古い結果」として出る（結果は、計算を始めたときの値のもの）。
- **完了しても音や動きで知らせない。** 状態の表示が変わり、スコープに波形が出る。読み上げには「実行 3 完了」を伝える。
- **フォーカスを動かさない。** 実行・完了・失敗でフォーカスの位置を変えない（値を直しては実行、をくり返せる）。例外は、実行できないときに Ctrl+Enter を押した場合（7.4）。

### 7.4 操作

|---|---|
| 「実行」を押す、Ctrl+Enter | 計算を始める。編集中の入力があれば先に確定する |
| 実行できないときに Ctrl+Enter、件数を押す | 最初の不足またはエラーの行にフォーカスが移り、お知らせが開く。計算は始まらない |

| 「理由を見る」を押す | お知らせが開き、その失敗の行にフォーカスが移る |

高さの内訳（1280×720、回路図が既定の高さ、カーソルなし、信号2本）: スコープ 460 ＝ 道具の列 32 ＋ 段 304（1段 152）＋ 時間軸 28 ＋ 表 96。

**① 道具の列。** 左端に領域の名前「スコープ」（見出しの行を別に取らない）。ボタンはアイコン＋言葉。左から:

| 要素 | 中身 |
|---|---|
| 全体 | 時間の全範囲を表示し、全段の縦軸を自動に戻す |
| 前の範囲 | 1つ前の表示範囲に戻る（最大20回分を覚える） |
| カーソル（押し込み式） | カーソル A・B の表示・非表示 |
| 比較（押し込み式） | 比較対象の波形の表示・非表示。比較対象が無いときは使えない（ツールチップに理由） |
| 固定（押し込み式） | 比較対象を入れ替えない（8.4 比較）。比較対象があるときだけ使える |
| 比較の説明 | 「実行 2 と比較 ・ 違い: R 1 Ω → 2 Ω」。比較が入のときだけ出る。違いは2件まで並べ、それ以上は「ほか n 件」。押すと全部の違いを小さな面で見せる |
| CSV… | 書き出しの小さな面を開く |
| 結果の説明 | 「実行 3 ・ 3,184 点 ・ 時間刻み 3.14 µs」。いま見ている波形が、どの実行の、どれだけの細かさのものか。モデルを選べるテンプレートでは、モデルも出す（「実行 3 ・ スイッチングモデル ・ 172,401 点 ・ 時間刻み 50 ns」）。モデルの言葉は押せて、仕様パネルのモデルの行へ移り、選択欄を開く |

道具の列に入りきらないときは、比較の説明の違いを「違い {n} 件」に縮め（押すと全部の違いを小さな面で見せる）、次に結果の説明の点数を省く。実行の番号、モデル、時間刻みは省かない（波形を信じてよいかに関わるため）。

**② 結果についての帯。** いま見ている波形を、そのまま信じてよいかに関わることを、波形のすぐ上に出す。次の2種類。両方あるときは2行。

| 種類 | 出る条件 | 中身 |
|---|---|---|
| 古い結果 | 波形を計算したときの値と、いまの仕様の値が違う | 注意の記号と「古い結果」、どの実行のものか、違い（2件まで、それ以上は「ほか n 件」）、「再実行」のボタン。値を元に戻して違いが無くなれば消える |
| 計算からの注意 | 計算エンジンが、その結果に注意を付けた（時間刻みが粗い、など） | 注意の記号と「注意」、1件目の「何が起きたか」、直す場所へのリンク（「時間刻みへ」）。2件以上なら「ほか n 件」（押すとお知らせへ）。その結果を見ている間、出続ける |

波形は薄くしない（読める状態のまま、帯で知らせる）。お知らせの帯は画面の下にあって、波形を見ている目に入りにくいので、波形の正しさに関わるものだけはここにも出す。

**③ 段。** 1つの段は1つの縦軸、1つの単位。

- 単位の同じ信号を1つの段に重ねて描く。単位の違う信号は別の段に分ける。**1つの段に2つの縦軸を置かない**（どちらの目盛りで読むかを取り違えるため）。時間軸は全段で共通で、カーソルも全段を貫くので、段をまたいだ時刻の比較はできる。
- 段は最大4つ、高さは等分。
- 段の左に縦軸（幅 64）。上端に単位（接頭辞つき: `V`、`mA`）。単位の無い量（デューティの指令、ゲート信号）の段は、上端に「無次元」と書く（単位の書き忘れに見せない）。単位の無い信号どうしは同じ段に入る。
- 段の左上に、その段の信号の凡例（色見本と信号名。比較対象は破線の色見本と実行番号）。画面を画像にして資料に貼っても、どの線が何か分かる。
- 段の右上に縦軸の切り替え「自動 / 固定」。
- 線の描き方（太さ、帯、サンプルの印、カーソル）は `design-system.md` 7章。

**④ 時間軸。** 全段で共通。右端に単位（接頭辞つき: `ms`、`µs`）。ポインタが波形の上にある間、ポインタの線の位置に、その時刻を小さな札で出す（`2.340 ms`）。

**⑤ 信号と読み取りの表。** 凡例と数値の読み取りを1つの表にまとめる。数値を読む場所はここだけにし、波形の上に値の吹き出しを出さない（波形を隠さない。桁のそろった等幅の数字で読める）。

| 列 | 中身 |
|---|---|
| 表示 | チェックボックス ＋ 色見本。その信号を波形に出すか |
| 信号 | 信号名（等幅）。ツールチップに説明（付録A） |
| 段 | その信号を描く段の番号。選択欄で変えられる |
| ポインタ | 波形の上にポインタがある間、その時刻の値。無いときは空 |
| A、B | カーソルの位置の値。カーソルを出していないときは、列ごと出さない |
| Δ (B−A) | B の値 − A の値。カーソルを出していないときは、列ごと出さない |

- 行の高さは 24（仕様パネルより詰める。波形に高さを回すため）。
- 見出しは、カーソルを出していないとき1行（24）。出しているとき2行（40）になり、2行目に A・B の時刻、Δ の列に Δt と 1/Δt を出す。A・B の時刻は押して数値を入れられる。
- 行は、表示している信号だけを付録Aの順に並べる。表示していない信号は、最後の行「ほかの信号（n）」にたたんであり、押すと下に開く（開いたままにもできる）。
- 比較が入のとき、表示中の各信号の下に、比較対象の行（破線の色見本、実行番号、A・B・Δ）が入る。
- **この結果に無い信号。** 表示していた信号が新しい結果に無いとき（モデルを「平均」に替えた、など）は、行を消さずに同じ位置に残す。表示のチェックボックスを使えない状態にし、値の欄を `—`、信号名の右に「この結果にはありません（平均モデル）」と出し、波形は描かない。その信号のある結果に戻れば、同じ色・同じ段で描く。比較対象にだけある信号、今回にだけある信号も、無い側の値を `—` にする。黙って行を消すと、隠したのか無いのかが分からなくなるため。
- 表の高さは中身に合わせ、最大でスコープの高さの 40%。それを超える分は表の中をスクロールする（見出しは残る）。

**読み取りの値の決まり。**

- カーソルは、いちばん近いサンプルの時刻に吸い付く。A・B の値は、**そのサンプルの値そのもの**（画面用に間引いた値ではなく、計算結果の値）。
- 比較対象は時間刻みが違うことがあるので、カーソルの時刻で前後のサンプルを直線で補間し、値の前に `≈` を付ける。時刻がちょうどサンプルに当たるときは `≈` を付けない。比較対象の時間範囲の外なら `—`。
- ポインタの列は、画面に描いている点から読む。1列に複数のサンプルが入っているときは、その列の最小〜最大を範囲で出す（2.1）。
- 桁数は 2.1。Δ は丸める前の値どうしで計算する。

**最初の見え方（仕様を開いて最初に完了したとき）。** テンプレートの「既定で表示する信号」（付録A）を出し、単位ごとに段を分ける（並びは、既定の信号の順に最初に現れた単位から）。時間は全範囲、縦軸は全段自動、カーソルと比較は切。

**2回目以降の実行。** 信号の選び方、段の割り当て、表示範囲、縦軸の自動／固定、カーソルの位置、比較の入／切を引き継ぐ（値を変えては同じ場所を見比べる、をくり返せる）。新しい結果の時間範囲が、見ていた範囲を含まないときだけ、全体表示に戻す。

| 状態 | 見え方 |
|---|---|
| 読み込み中（最初の計算中） | 波形の位置に「計算しています…」と、ヘッダーと同じ進み具合 |
| 読み込み中（完了してから波形が届くまで） | 200 ms たっても届かないとき「波形を読み込んでいます…」 |

| エラー（計算が失敗し、前の結果も無い） | 波形の位置に「実行 {n} が失敗しました。」と「理由を見る」 |

### 8.4 操作

**拡大縮小と移動（マウス）。** 回路シミュレータの波形表示の慣習（ドラッグで範囲を選んで拡大、軸をつかんで移動、ダブルクリックで全体）に合わせる。

| 操作 | 結果 |
|---|---|
| 波形の上で左右にドラッグ | 選んだ時間範囲に拡大（全段共通）。ドラッグ中は選んでいる範囲に帯が出る。縦軸は変えない（自動なら、新しい範囲に合わせ直される） |
| Shift を押しながらドラッグ | 囲んだ四角に拡大（時間は全段、縦はその段だけ。その段の縦軸は固定になる） |
| ドラッグ中に Esc、または 4px 未満で離す | 取り消し |
| ホイール（波形の上） | ポインタの時刻を中心に時間軸を拡大・縮小。1刻みで表示範囲が 0.8 倍 / 1.25 倍（回した量に比例） |
| Shift＋ホイール、横向きのスクロール | 時間方向に移動 |
| 時間軸を左右にドラッグ | 時間方向に移動 |
| 縦軸の上でホイール | その段の縦方向を拡大・縮小（固定になる） |
| 縦軸を上下にドラッグ | その段を縦方向に移動（固定になる） |
| 波形の上でダブルクリック | 全体表示（「全体」と同じ） |
| 縦軸をダブルクリック、時間軸をダブルクリック | 範囲を数値で入れる小さな面を開く（最小・最大、または開始・終了。2章の入力規則。縦軸には「自動に戻す」がある） |
| 段の右上の「自動 / 固定」を押す | 切り替える。固定にしたときは、いまの範囲を保つ |

- 縦軸が「自動」のとき、範囲は、その段に表示している全信号（比較対象を含む）の、表示中の時間範囲での最小〜最大に、上下 5% の余白を足したもの。値が一定のときは、その値の ±5%（0 のときは ±1）。
- 時間の範囲は、データのある範囲（0〜終了時刻）の外へは出ない。いちばん拡大したときの幅は、サンプル8個分。
- 拡大縮小に動きを付けない（途中の絵を描かない）。

**カーソル。** オシロスコープの慣習（2本の縦のカーソルで Δt、1/Δt、値の差を読む）に合わせる。

| 操作 | 結果 |
|---|---|
| 「カーソル」を押す、C | A・B を出す／隠す。最初に出すときは、表示範囲の左から 1/3 に A、2/3 に B（いちばん近いサンプルに吸い付く）。隠して出し直したときは、前の位置 |
| カーソルの旗か線をドラッグ | そのカーソルが動き、選ばれた状態になる。読み取りの値が追従する。線のつかめる幅は 12px |
| 表の A・B の時刻の欄を押して数値を入れる | その時刻（にいちばん近いサンプル）へ移る |
| A、B（キー） | そのカーソルを選ぶ。カーソルが隠れていたら出す。選んだカーソルが表示範囲の外にあるときは、表示範囲の中央へ移す |
| ← / →（カーソルを選んでいるとき） | 画面の1列分、動かす（十分に拡大していればサンプル1個分）。Shift を押すと10列分 |
| Esc | カーソルの選択を外す |
| プロットの端の「◀ A」「B ▶」を押す | そのカーソルが見える位置まで時間方向に移動する |

- カーソルが表示範囲の外にあっても、表の値は出たまま（消さない）。
- A が B より右にあってもよい。Δ は常に B − A（符号つき）。1/Δt は絶対値。

**信号と段。**

| 操作 | 結果 |
|---|---|
| 表のチェックボックス、行にフォーカスしてスペース、回路図の測定点の印 | その信号を出す／隠す。出すときは、同じ単位の段があればそこへ、無ければ新しい段へ。ほかの信号の色・段・縦軸は変わらない |
| 表の「段」の選択欄 | その信号を別の段へ移す。選べるのは、同じ単位の段と「新しい段」。単位の違う段は選べない状態で出し、理由（「単位が違う: A」）を添える |
| 表の行にポインタを乗せる、フォーカスする | その信号の線を 2.5px にする（どの線かを確かめられる） |
| 信号が1本も無くなった段 | 自動で消え、残りの段が詰まる |
| 段が4つあるときに、新しい段が要る信号を出そうとした | 出さずに、お知らせ N-PLOTS-FULL |
| 9本目の信号を出そうとした | 出さずに、お知らせ N-SIGNALS-FULL |

**比較。** 回路シミュレータの「前の波形を残しておく」機能に当たる。

| 操作 | 結果 |
|---|---|
| 実行が完了する（固定が切） | それまで見ていた結果が「比較対象」になり、新しい結果が「今回」になる。比較対象は1つだけ持つ |
| 実行が完了する（固定が入） | 比較対象は変わらない。新しい結果が「今回」になる（値を何度か変えて、最初の結果と比べ続けられる） |
| 実行が中断・失敗した | 今回も比較対象も変わらない |
| 「比較」を押す、R | 比較対象の波形を、表示中の信号について重ねる／外す。道具の列に、どの実行と比べているかと、仕様の違いが出る |
| 「固定」を押す | 入／切 |
| 別の仕様を開く | 今回も比較対象も消える。固定は切になる |

- 比較対象は、今回と同じ色の破線で、今回の線の後ろに描く（`design-system.md` 3.4）。
- 「違い」は、比較対象を計算したときの値と、今回を計算したときの値の違い（項目の記号、前の値 → 今の値）。違いが無ければ「違いなし」。
- 比較対象の時間範囲が今回より短いときは、ある範囲だけ描く。

**CSV の書き出し。** 「CSV…」を押すと小さな面が開く。

```
┌ CSV に書き出す ─────────────────────────────────┐
│ 信号    (●) 表示中の信号（2）  ( ) すべての信号（5）│
│ 範囲    (●) 表示中の範囲（1.2 ms 〜 3.5 ms）       │
│         ( ) カーソル A〜B の間（1.234 ms 〜 3.456 ms）│
│         ( ) 全体（0 s 〜 10 ms）                   │
│                                                   │
│ 間引かずに全部のサンプルを書き出します。            │
│ 733 行 × 3 列、約 40 kB                           │
│ 値は基本単位（s、V、A）。比較対象は含みません。     │
│                                                   │
│                          [書き出す]  [やめる]      │
└───────────────────────────────────────────────────┘
```

- 書き出すのは「今回」の結果の、計算したままのサンプル（間引かない、補間しない）。
- 形式: UTF-8、コンマ区切り、改行は LF。1行目は見出しで、単位を角かっこで付ける（`t [s],v(out) [V],i(L1) [A]`）。単位の無い量は `[1]`（`cmd(duty) [1]`）。値は基本単位、元の値に戻せる桁数（17桁まで）の10進表記。接頭辞を付けない。
- ファイル名: `{仕様のファイル名（拡張子なし）}_run{実行番号}.csv`。ブラウザのダウンロードとして保存される。
- 範囲の「カーソル A〜B の間」は、カーソルを出しているときだけ選べる。
- 行数が 1,048,576 を超えるときは、注意の記号つきで「表計算ソフトでは全部の行を開けないことがあります（Excel の上限は 1,048,576 行）。」を足す。止めはしない。
- 古い結果、または計算からの注意が付いた結果を書き出すときは、注意の記号つきで、そのことを1行足す（「この結果は、仕様を変える前（実行 {n}）のものです。」「この結果には、計算からの注意が {n} 件あります。」）。

**キーボード（波形にフォーカスがあるとき）。**

| キー | 結果 |
|---|---|
| ← / → | カーソルを選んでいなければ、表示範囲の 10% だけ時間方向に移動。選んでいれば、カーソルを動かす |
| Shift+← / Shift+→ | 表示範囲の 50% 移動（カーソルなら10列分） |
| + / −（; や = のキーでも可） | 時間軸を 2倍に拡大 / 2倍に縮小。中心は、選んでいるカーソル（表示範囲の中にあれば）、無ければ表示範囲の中央 |
| Home / End | 幅を変えずに、データの先頭 / 末尾へ |
| F | 全体表示 |
| Backspace | 前の表示範囲 |
| C | カーソルを出す／隠す |
| A / B | カーソル A / B を選ぶ |
| R | 比較を出す／外す |
| Esc | カーソルの選択を外す。ドラッグの取り消し |

縦軸の範囲は、縦軸にフォーカスして Enter で数値入力の面を開く（縦軸も Tab で止まる）。

## 9. お知らせ（S7）

### 9.1 用事

いま困っていること（足りない値、失敗、注意）が何件あるかを常に見て、1件ずつ、何が起きたかと直し方を読み、直す場所へ移ること。

### 9.2 要素と配置

画面の下端に、幅いっぱいの帯。

```
たたんだ状態（高さ 32）
│ お知らせ │ ✕ エラー 1 ・ ◌ 不足 2 ・ ⚠ 注意 1 │ 実行 4 が失敗しました: t = 1.234 ms で、スイッチと…          [ˆ] │

開いた状態
┌ お知らせ │ ✕ エラー 1 ・ ◌ 不足 2 ・ ⚠ 注意 1 ───────────────────────────────────────────────────── [ˇ] ┐
│ ✕ エラー  実行 4 が失敗しました: t = 1.234 ms で、スイッチとダイオードの状態が決まりませんでした。            │
│           時間刻みを小さくして、もう一度実行してください。            [時間刻みへ]  [詳細]         14:02:11  [×] │
│ ◌ 不足    C（静電容量）の値が入っていません。  仕様パネルで値を入力してください。   [C へ]                  │
│ ◌ 不足    R_load（負荷抵抗）の値が入っていません。  仕様パネルで値を入力してください。 [R_load へ]         │
│ ⚠ 注意    スコープの波形は、仕様を変える前（実行 3）のものです。                                          │
│           いまの値の波形を見るには、もう一度実行してください。       [実行]                               │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

- 見出しの件数は、段階ごとに記号＋言葉＋数。0 件の段階も出す（`text-muted`）。
- たたんだ状態では、件数の右に、いちばん重い段階の最新の1件の「何が起きたか」を1行で出す（入りきらなければ省略）。
- 並び順: エラー → 不足 → 注意。同じ段階の中は、出来事のお知らせは新しい順、状態のお知らせは仕様パネルの行の順。
- 1件の中身（`design-system.md` 6.6）: 段階、何が起きたか、どう直すか、直す場所へ移るリンク、時刻（出来事だけ）、閉じる（利用者が消せるものだけ）。プログラムの内部の文があるときは「詳細」で開く。
- 開いたときの高さは中身に合わせ、最大でウィンドウの高さの 40%。それを超える分は帯の中でスクロールする。開くとスコープがその分低くなる（上に重ねて波形を隠すことはしない）。

**お知らせの2つの種類。**

| 種類 | 例 | 消えるとき |
|---|---|---|
| 状態のお知らせ | 不足、入力エラー、単位の誤り、ステップ数の上限、時間刻みが粗い、古い結果 | 原因が無くなったら自動で消える。利用者は消せない（値を大きく変えたときの注意 N-BIG-CHANGE だけは、確かめた後に閉じられる） |
| 出来事のお知らせ | 開けなかった、計算が失敗した、計算からの注意、書き出せなかった | 開く系は次に開く操作をしたとき、計算の失敗は次の実行が始まったとき。それまでに「閉じる」でも消せる。結果に付いた計算からの注意は、その結果をスコープで見ている間は残り、閉じられない（波形の上の帯と対になっている） |

全部の一覧と文言は付録B。

## 10. 言語とテーマ（S8）

### 10.1 用事

自分の読みやすい言語と、部屋の明るさに合った色で使うこと。切り替えても、作業が途切れないこと。

### 10.2 要素と配置

ヘッダーの右端に、切り替えを2つ並べる（`design-system.md` 6.2）。

```
[日本語|English]  [明|暗]
```

- 言語の選択肢は、どちらの言語で表示していても「日本語」「English」と書く（読めない言語にしてしまっても戻れる）。
- テーマの選択肢は、表示中の言語で書く（明 / 暗、Light / Dark）。

### 10.3 状態

| 状態 | 見え方 |
|---|---|
| 読み込み中 | 無い（辞書と色は最初から画面に入っている。切り替えのために通信しない） |
| 空（はじめて開いた） | 言語: ブラウザの言語が日本語なら日本語、それ以外は英語。テーマ: OS の設定が暗なら暗、それ以外は明 |
| 正常 | 選んだ言語とテーマ。ブラウザに覚えさせ、次に開いたときも同じ |
| エラー（辞書に無いキー） | 開発中の検査で落とす（AC-10-3）。利用者の画面では、もう一方の言語の文言を出す（キーの名前をそのまま出さない） |

### 10.4 操作

| 操作 | 結果 |

## 12. 画面が必要とするデータ

API の形は ui-engineer が決める。ここには、画面がこの仕様どおりに動くために、アプリ本体から受け取る必要のあるものを書く。

| # | 必要なもの | 中身 | 速さ |
|---|---|---|---|
| D1 | サンプルの一覧 | 名前と説明のキー、テンプレート名 | 200 ms 以内 |
| D2 | テンプレートの表示定義 | 付録A.1 の内容 | 200 ms 以内 |
| D3 | 仕様の確かめ（計算の前に分かること） | 開けるか（開けないなら、お知らせの番号と差し込む値）。開けるなら、項目ごとの状態（通常・不足・既定値・範囲の外・単位の誤り）、単位を換算した項目の一覧（書かれていた値と単位、換算後の値）、計算の設定の自動の値、ステップ数とその上限、計算の前に出せる注意（時間刻みが粗い、など） | 値を変えてから 100 ms 以内に画面が変わること |
| D4 | 実行 | 開始。進み具合（0〜1。出せないときは「不明」と分かる形）。中断。終わり方（完了: 実行番号、所要時間、ステップ数、時間刻み、信号の一覧と単位、計算からの注意、計算に使った仕様の写し ／ 失敗: お知らせの番号と差し込む値、内部の文） | 進み具合は 0.5 秒に1回以上。中断は 1秒以内 |
| D5 | 波形（画面用） | 信号、時間範囲、横の画素数を渡すと、画素の列ごとの最小値と最大値（とその列のサンプル数）。サンプルが列より少ない範囲では、サンプルそのもの。今回と比較対象のどちらも | 2000万点 × 2信号で、AC-8-2 を満たすこと |
| D6 | カーソルの値 | 時刻を渡すと、いちばん近いサンプルの時刻と、その時刻の各信号の値（今回）。比較対象は、その時刻で補間した値と、補間したかどうか | AC-8-7 を満たすこと |
| D7 | CSV | 信号と時間範囲を渡すと、8.4 の形式のファイル。行数と大きさの見積もり | 見積もりは 200 ms 以内 |
| D8 | つながっているかの確かめ | — | 5秒以内に切断に気づけること |
| D9 | 状態の復元 | 再読み込みの後、開いている仕様、編集内容、今回と比較対象の結果（と、それぞれを計算したときの値）を取り戻せること | — |

- エラーと注意は、文面ではなく **番号と差し込む値** で受け取る（文面は画面の辞書が持つ。日英を切り替えられるようにするため）。番号の付いていないものは N-RUN-INTERNAL / N-RUN-NOTE-OTHER として、内部の文を「詳細」に入れる。
- 画面は、表示する数値を自分で丸め直すが、Δ の計算や一致の判定には、受け取った値をそのまま使う。
- 降圧コンバータでは、D2 にモデルの選択肢とモデルごとの信号の有無、D3 に Tf の自動の値、組で入れる値の片方の不足、f_sw と f_ctrl の比、指令値がデューティの上下限で届くか、段差の時刻が終了時刻より後か、負荷の段差の時刻の切り上げ、も含める（付録A.4）。
- **単位の換算、範囲の判定、ステップ数の上限、時間刻みの粗さの判定は、計算エンジンが行う。** 画面（とアプリのサーバー）が同じ判定を別に持たない。コマンドラインと画面で結果が食い違わないようにするため。エンジンの判定が計算を始めた後にしか出ない場合の受け皿も用意してある（ステップ数は N-RUN-STEPS、注意は N-RUN-NOTE-…）。

## 付録A テンプレートの表示定義

### A.1 表示定義に書くもの

画面は、テンプレートごとの「表示定義」から、仕様パネルの行、回路図、スコープの信号を作る。新しいテンプレートは、表示定義を足せば画面に出る。

| 項目 | 中身 |
|---|---|
| テンプレート | 名前（`rlc_series`）、表示名（日英） |
| 項目（仕様パネルの行） | 群、並び順、仕様の中の位置（`plant.R`）、記号、名前と説明（日英）、単位、必須か（必須でなければ既定値・自動の値と、その意味。組で入れる相手）、範囲、対応する図の素子 |
| 信号 | 並び順（＝色の番号）、名前（`v(out)`）、説明（日英）、単位、既定で表示するか、モデルごとの有無、対応する図の測定点 |
| 図 | 素子・節点・測定点の配置、電源の波形の書き方。モデルで描き替える部分 |
| モデル | スイッチを含むテンプレートだけ。選べるモデルと既定（5.2） |

- 項目の名前・単位・必須・範囲と、信号の名前・単位は、テンプレートを作る側（solver-engineer、control-engineer）が決める。表示名・説明の文言・図の配置は ux-designer が決める。
- 座標は目安（±10px は実装で調整してよい）。変えてはいけないのは、素子の並び、極性、矢じりの向き、ラベルの中身。

**文言のキー。** テンプレートの文言は、次のキーで辞書に持つ（「キー | 日本語 | English」の表に書けば、辞書の生成が拾う。付録A.4 の文言の表）。

| 文言 | キー |
|---|---|
| 表示名 | `template.<テンプレート>.name` |
| 項目の名前 | `item.<テンプレート>.<記号>.name`（計算の設定の項目は、テンプレートによらない `spec.sim.*`） |
| 項目の説明（ツールチップ） | `item.<テンプレート>.<記号>.desc`（計算の設定の項目も、自動の値の決め方はテンプレートごとなので、ここに持つ） |
| 信号の説明 | `signal.<テンプレート>.<信号名>.desc` |

### A.2 RCローパス（`rc_lowpass`）

表示名: RCローパス / RC low-pass

**項目。**

| 群 | 位置 | 記号 | 名前（日 / 英） | 単位 | 必須 | 範囲 | 図の素子 | 説明（日 / 英） |
|---|---|---|---|---|---|---|---|---|
| 回路 | `plant.Vin` | `Vin` | 入力電圧 / Input voltage | V | 必須 | 有限 | V1 | t = 0 で 0 V からこの値に切り替わる / Steps from 0 V to this value at t = 0 |
| 回路 | `plant.R` | `R` | 抵抗 / Resistance | Ω | 必須 | 0 より大きい | R1 | — |
| 回路 | `plant.C` | `C` | 静電容量 / Capacitance | F | 必須 | 0 より大きい | C1 | — |
| 計算の設定 | `simulation.t_end` | `t_end` | 終了時刻 / Stop time | s | 自動あり | 0 より大きく、時間刻みより長い | — | 自動のときは、時定数 RC の5倍 / Auto: 5 × the time constant RC |
| 計算の設定 | `simulation.h` | `h` | 時間刻み / Time step | s | 自動あり | 0 より大きい | — | 自動のときは、2π·RC の 1/200 / Auto: 2π·RC ÷ 200 |

**信号。**

| 番号（色） | 名前 | 単位 | 既定で表示 | 説明（日 / 英） |
|---|---|---|---|---|
| 1 青 | `v(out)` | V | する | 出力電圧（C1 の電圧） / Output voltage (across C1) |
| 2 橙 | `i(V1)` | A | する | 電源 V1 の電流。V1 の中を ＋ から − へ流れる向きが正（回路へ電流を送り出しているときは負） / Current through source V1, positive from + to − inside the source (negative while V1 delivers current) |
| 3 水色 | `v(in)` | V | しない | 入力電圧（V1 の電圧） / Input voltage (across V1) |

**図。** 描く範囲 520 × 172（回路図の領域の既定の高さ 180 に、原寸で収まる）。縦の割り付けは、測定点の枠の列 y = 16、素子の名前 y = 38、上の配線 y = 60、値 y = 84、電源とコンデンサの中心 y = 105、下の配線 y = 150、基準点 y = 150〜168。

```
