# 調査と設計検討の資料

方向の転換（D-068、D-069）を受けて行った調査と設計検討。計画を組み直すための材料で、設計の「正」ではない（正は `docs/design/`）。結論は決定記録（`docs/decisions.md`）に書く。

| 資料 | 中身 | 担当 | 日付 |
|---|---|---|---|
| `landscape.md` | 既存の道具との比較、土台にできる既存のオープンソースとライセンスの判定、既存の道具の拡張として作る選択肢、差別化の検証 | 調査担当 | 2026-11-16 |
| `academic-extension.md` | 電動機（誘導機、PMSM、同期機、DC 機）の入れ方、制御で作る仮想の素子、研究・教育で要る機能、読み取る値と換算の約束 | control-engineer | 2026-11-16 |
| `extraction-approach.md` | 設計書とデータシートからの読み取りの方式（生成 AI、スクリプト、学習済みモデル）の比較、照合の仕組み、評価の方法 | ingest-engineer | 2026-11-16 |
| `devices-and-solver.md` | 素子の一覧（約40種、3つの水準）、既存のエンジンのライセンスの判定、解法の比較と実測、2つの水準（系統 / 素子）の案 | solver-engineer | 2026-11-16 |

ライセンスの判定は3段階（○ 明確に緩い / △ 緩いが同梱物や依存に一覧の外のライセンスが混ざる / × 使えない）。△ の扱いは PO の判断待ち。

| `vendor-tools.md` | 半導体メーカーの無料の設計ツール（LTpowerCAD、WEBENCH、DCDT、ST-WDS ほか）と v0.1 の比較 | 調査担当 | 2026-11-17 |

4つの検討をまとめた提案は `docs/plan/direction-proposal.md`。

検討の中の割合（既存 / 自作）は工数の見積もりで、測ったものではない。検討は担当ごとの報告で、独立の検証は受けていない（オーケストレーターが自分で確かめたのは、NumPy・SciPy の Linux のホイールが libquadmath を同梱し LICENSE に LGPL の記載があること、Claude の公式文書のログインの扱いの2点）。
