## 0. 要点

1. **既存のものの割合（D-069）。** 電動機と制御の領域で、式と数値の部品（電動機のモデルの式、座標変換、伝達関数と離散化、最適化）は既存のもので大半を賄える。ただし、ライセンスを厳しく見ると、**依存としてそのまま入れられる電動機・制御のライブラリは無い**（motulator、gym-electric-motor、python-control は、本体は MIT / BSD だが、推移的な依存の matplotlib（独自の文面）や tqdm（MPL-2.0）が要る）。使えるのは「MIT のコードを表示つきで取り込む」形と、すでに依存にある SciPy（ただし同梱物のライセンスが D-069 の字義では「混在」に当たる。11.3）。自前の回路エンジンに電動機を入れる場合（道1）では、既存のものの割合は工数でおよそ 2〜3 割、自作が 7〜8 割。電動機のドライブを式のレベルのシミュレータ（motulator と同じ作り）で計算する場合（道2）なら、既存のもの（取り込み）が 6〜7 割になる（12章）。
2. **誘導機の勧め。** 3段で入れる。(c) 等価回路の定常解析（エンジンを触らない。教育の価値が高く、検証が易しい）→ (d) 回転座標の状態平均化モデル（制御の設計用。線形化してゲインを決める）→ (a) 機械の素子が自分の状態方程式を持ち、固定子は「一定の抵抗とインダクタンス＋逆起電力の電源」で回路とつなぐ形（電圧ビハインドリアクタンス、逆Γ形）。(b) 角度で変わる abc の相互インダクタンスを行列に入れる案は、行列の作り直しが 1 ステップの 400〜1000 倍かかる（実測。3.2）ので、いまの固定刻み・区分線形の核では勧めない。解法が非線形（毎ステップの組み立て直し）に移るなら評価を見直す。
3. **PMSM（表面磁石形）は (a) にそのまま乗る**（端子のインダクタンスが角度によらない）。埋込磁石形と同期機（突極）は端子のインダクタンスが角度で変わるので、一定の部分＋電源で表す方式か、機械の端子だけの更新が要る（解法への要求 R-1）。DC 機（磁束一定）は、従属電源と機械系の電気的な類推（慣性 ↔ 容量）で行列のまま表せる。
4. **仮想の素子。** 仮想抵抗・仮想容量・仮想インダクタンス（並列と直列）、仮想同期発電機（疑似慣性）、直流リンクの仮想容量は、どれも「検出値 → 伝達関数 → 指令の足し込み」の制御ブロックで表せる。いまの PID だけの部品では足りず、伝達関数・状態空間のブロック、座標変換、PLL、電力の計算、ブロック図の記述が要る（V1）。演算遅れ 1 サンプル＋保持 0.5 サンプルで、仮想抵抗は fs/6 より上で負性抵抗になる（6.3 で導出。Pan ら 2014 の結論と一致）。
5. **「仮想容量」の意味は PO に確かめる。** 候補は6つ（6.1）: 制御で作る仮想キャパシタ、直流リンク・直流マイクログリッドの仮想容量（仮想慣性）、交流系統の疑似慣性、計算の都合で置く架空のコンデンサ（架空のスナバ）、自己励磁誘導発電機の励磁用コンデンサ（実在の素子。「励磁」と結びつく）、定格容量（kVA）。
6. **計画。** v0.1〜v0.3 の作業単位（E1g → E1f → E1h → E2a → E2b、A0〜A3、I1、I2）には割り込まない。いま始めてよいのは、文書だけの M0（モデル定義書と既存のものの採否）と、エンジンを触らない M1（誘導機の定常解析）。制御ブロックの拡充（V1）と DC 機・機械系の口（M2）は E3 の前提として E3 の手前に置く。核に機械の素子の口を開ける M3 は、solver-engineer の解法の方針（D-068）が決まってから。

## 2. 電動機の式

### 2.1 記号、座標、変換

- 空間ベクトル（space vector）は複素数で書く（x = x_α + j x_β）。静止座標（αβ。stationary reference frame）と、回転子座標（dq。rotor reference frame）を使う。
- 変換は**振幅不変**（amplitude-invariant。係数 2/3）に統一する。αβ の変換は [x_α; x_β] = [2/3, −1/3, −1/3; 0, 1/√3, −1/√3]·[x_a; x_b; x_c]、dq は (2/3)·[cos θ_e, cos(θ_e − 120°), cos(θ_e + 120°); −sin θ_e, −sin(θ_e − 120°), −sin(θ_e + 120°)]·[x_a; x_b; x_c]（出典 [S12]、[S13]）。この取り方ではトルクの式に 3/2 が付く。電力不変（係数 √(2/3)）の取り方では 3/2 が消え、磁石磁束の値の意味も変わる（[S11]）。**どちらの取り方かを、モデル定義書（M0）と結果に必ず書く**（読み取った値の換算で取り違えやすい。8章）。
- 極対数（pole pairs）p、機械角速度 ω_m、電気角速度 ω_e = p·ω_m、電気角 θ_e = p·θ_m（[S6]、[S12]）。
- 機械系: J·dω_m/dt = T_e − F·ω_m − T_L、dθ_m/dt = ω_m（[S6]）。負荷トルク T_L は差し替え式の負荷の口から来る（決まり6）。

### 2.2 誘導機（induction machine）

**等価回路（定常、1相、固定子側に換算）。**

- T形等価回路（T-equivalent circuit）: 固定子の抵抗 R_s と漏れリアクタンス X_ls、励磁リアクタンス X_m（magnetizing reactance）、回転子の抵抗 R_r' と漏れリアクタンス X_lr'（固定子側に換算）。回転子の枝のインピーダンスは R_r'/s + jX_lr'。鉄損（iron / core loss）は、励磁の枝に並列の鉄損抵抗 R_c で表すのが普通（[S10] は R_c を入力の端に置く形）。
- すべり（slip）s = (ω_s − p·ω_m)/ω_s（ω_s は電源の角周波数、p は極対数）。機械の同期速度 ω_sm = ω_s/p。トルクの式は 2極の形で書き、多極では機械量に換える（[S1] の 7。[S1] は p を極数として ω_sm = 2ω_s/p と書く）。
- 励磁電流（magnetizing current）は励磁の枝を流れる電流。無負荷では回転子の枝がほぼ開放で、入力電流のほとんどが励磁電流になる（[S9] の式 (16) X_nl = X_1 + X_m）。
- **テブナン等価（Thevenin equivalent）**（[S1]）:
  V_TH = V_a·jX_m / (R_a + j(X_a + X_m))、Z_TH = (R_a + jX_a)(jX_m) / (R_a + j(X_a + X_m))
  （[S1] の記号: R_a、X_a が固定子、R_r、X_r が回転子）
- **トルク**（[S1]。2極。p 極対では ω_s を機械の同期速度に換える）:
  T_e = 3·V_TH²·(R_r/s) / (ω_s·[(R_TH + R_r/s)² + (X_TH + X_r)²])
- **停動トルク（breakdown torque。最大トルク）とそのすべり**: [S1] は簡易等価回路で s_mT = R_r / √(R_a² + (X_a + X_r)²)、R_a ≈ 0 で T_max = 3·V_a² / (2·ω_s·(X_a + X_r)) を示し、T_max は R_r によらない（R_r は最大になるすべりだけを動かす）と書く。テブナン等価では V_a、R_a、X_a を V_TH、R_TH、X_TH に置き換えて s_maxT = R_r / √(R_TH² + (X_TH + X_r)²)、T_max = 3·V_TH² / (2·ω_s·[R_TH + √(R_TH² + (X_TH + X_r)²)])（この置き換えはこの文書で行った。M1 で教科書の原典と照合する）。
- 始動トルク（starting torque。s = 1）、エアギャップ電力 P_ag = 3·I_r²·R_r/s、機械出力 P_m = (1 − s)·P_ag（[S1]）。回転子の銅損は s·P_ag（P_ag − P_m から）。
- **L形（簡易）等価回路（approximate / L-equivalent circuit）**: 励磁の枝を端子に移した近似。I_r = V_a / ((R_a + R_r/s) + j(X_a + X_r))（[S1] の 1）。教育では T形との差を見せる題材になる。
- **Γ形・逆Γ形（Γ / inverse-Γ model）**（Slemon 1989 [S2]。式は [S3]）: 漏れを片側に寄せた、パラメータが1つ少ない等価な形。逆Γ形は回転子磁束を向きの基準にする制御で使う。T形からの換算（この文書で導出。[S3] の Γ → 逆Γ の関係 L_sσ = γL_ℓ、L_M = γL_s、R_R = γ²R_r と一致することを確かめた）:
  L_M = L_m²/L_r、L_σ = L_s − L_m²/L_r（= σ·L_s）、R_R = (L_m/L_r)²·R_r。ここで L_s = L_ls + L_m、L_r = L_lr + L_m。
- **二重かご形（double-cage）**: 回転子の枝を2つ並列にする（R_r1、X_r1、R_r2、X_r2）。トルクは T = (R_r1/s)·I_r1² + (R_r2/s)·I_r2²（単位法。[S10]）。深溝形（deep-bar）は、回転子のインピーダンスの周波数依存として表す（motulator は R_r を「かごのインピーダンス Z_c(s)」に置き換える。[S3]）。

**過渡（空間ベクトル。逆Γ形。静止座標。飽和なし）。** [S3] の状態方程式で座標の速度 ω_c = 0 と置いたもの:

  L_σ·di_s/dt = u_s − (R_s + R_R)·i_s + (α − jω_m)·ψ_R、 α = R_R/L_M
  dψ_R/dt = R_R·i_s − (α − jω_m)·ψ_R
  T_e = (3p/2)·Im{ i_s·ψ_s* }、 ψ_s = L_σ·i_s + ψ_R

（2行目は [S3] の回転子の式 dψ_r/dt = −R_r·i_r + jω_m·ψ_r と、ψ_R = γψ_r、i_R = i_r/γ、ψ_R = L_M(i_s + i_R) から導いた。この文書の導出で、照合は M5 の検証で行う。[S3] の ω_m は電気角速度。）

**この形の大事な点: 固定子の側から見ると、端子は「一定の抵抗 R_s + R_R と一定のインダクタンス L_σ と、ψ_R と ω_m で決まる電圧源 e_s = −(α − jω_m)·ψ_R の直列」に見える。** 回転子の角度で変わるインダクタンスが端子に出てこない。これが 3章の案 (a) の根拠。

**磁気飽和（magnetic saturation）。** 励磁インダクタンスを磁束の大きさの関数にする（[S3] は L_s(|ψ_s|)、PLECS は不飽和の値 L_m0、飽和の値 L_m,sat、変わり目の磁束 Ψ_T、形の係数 f_T で磁化曲線を表す [S5]）。逆Γ形では L_σ、R_R、L_M のすべてが磁束で変わり、磁束の大きさが変わるときだけ現れる電圧の項 ε が加わる（[S3]）。d 軸と q 軸の交差飽和（cross-saturation）の扱いと状態変数の選び方は Levi [S7] が統一的に整理している。

**鉄損。** 励磁の枝に並列の抵抗で表す。ベクトル制御への影響は Levi [S8]（題名と書誌だけ確かめた。中身は未確認）。

**自己励磁誘導発電機（self-excited induction generator）。** 固定子の端子にコンデンサをつないで励磁電流を供給し、単独で発電する。電圧はコンデンサが最小値を超えると立ち上がり、励磁インダクタンスの低下（飽和）で決まる値に落ち着く（[S29]）。**磁気飽和を入れないと、電圧の落ち着く値が計算できない。** Levi [S7] の検証の題材もこれ。

### 2.3 永久磁石同期電動機（PMSM）

回転子座標（[S13]。N は極対数、ω は機械角速度、ψ_m は磁石磁束（PM flux linkage））:

  v_d = R_s·i_d + L_d·di_d/dt − Nω·L_q·i_q
  v_q = R_s·i_q + L_q·di_q/dt + Nω·(L_d·i_d + ψ_m)
  T = (3/2)·N·[ψ_m·i_q + (L_d − L_q)·i_d·i_q]

第2項がリラクタンストルク（reluctance torque）。表面磁石形（SPMSM）は L_d = L_q、埋込磁石形（IPMSM）は L_d ≠ L_q（[S13]）。abc で見ると、L_d ≠ L_q のとき固定子のインダクタンスは回転子の角度で変わる（[S13] の L_d = L_s + M_s + (3/2)L_m、L_q = L_s + M_s − (3/2)L_m の L_m が角度で変わる成分。PLECS も L_d = L_q のときだけ角度によらないと書く [S12]）。

表面磁石形を静止座標に直すと（この文書で上の式から導出）、端子は「一定の R_s と L（= L_d = L_q）と、逆起電力 e = jω_e·ψ_m·e^{jθ_e} の直列」になる。逆起電力は角度と速度（機械系の状態）だけで決まる。

### 2.4 同期機（巻線界磁、制動巻線つき）

回転子座標で、固定子の d・q、界磁巻線（field winding）fd、制動巻線（damper winding）kd・kq の磁束鎖交数を状態に持つ（Krause ほか [S4]。章と式の番号は M0 で確かめる）。端子から見た過渡のインダクタンス（初期過渡リアクタンス L''_d、L''_q）が d と q で違う（初期過渡突極性）と、端子のインダクタンスが角度で変わる。固定子を abc の物理量で表す電圧ビハインドリアクタンスのモデルは Pekarek ら [S15]、その飽和の入れ方は [S16]。突極の分を一定の RL 枝で近似する方法は Chapariha ら [S17]。

### 2.5 DC 機

  v_a = R_a·i_a + L_a·di_a/dt + K·φ·ω_m、 T = K·φ·i_a

（[S14] は定常の式 V_T = E_A + I_A·R_A、E_A = Kφω_m、τ = Kφ·I_A。過渡では L_a·di_a/dt を足す。）結線は、他励・永久磁石（φ 一定）、分巻（界磁を端子電圧に並列。φ = c·I_F）、直巻（界磁を電機子に直列。φ = c·I_A）（[S14]）。φ 一定なら式は線形で、分巻と直巻は φ が電流で決まるので非線形（磁化曲線（magnetization curve）が要る。[S14] は飽和の曲線を示していない）。

### 2.6 「励磁」と「界磁」

PO の問いの「励磁」は、誘導機では励磁インダクタンス・励磁電流（磁化のための無効分）を指す。同期機と DC 機の「界磁（field）」も日本語で「励磁」と呼ぶ（励磁装置、励磁電流）。用語集（`glossary.md`）に足すときは、誘導機は「励磁インダクタンス（magnetizing inductance）」、同期機・DC 機は「界磁電流（field current）」を主にし、「励磁」は併記にする（M0 で決める）。

## 3. 電動機をエンジンに入れる案の比較

### 3.1 案 (a) 機械の素子が自分の状態方程式を持ち、回路とは電源でつなぐ

3つの結び方がある。

| 結び方 | 中身 | 長所 | 短所 | 出典 |
|---|---|---|---|---|
| (a1) 回転子座標モデル（RRF）を電流源でつなぐ | 端子電圧を測って dq に変換し、dq の電流を解いて、制御された電流源で回路に流す | 係数が一定で速い | 端子電圧が常に決まっていなければならない。ダイオード整流器、デッドタイムのあるインバータ、端子に直結したインダクタや電流源をつなげない。そのときは端子に**架空のスナバ（fictitious snubber）**の抵抗を並列に置くが、機械を迂回する電流でトルクに誤差が出て、値が大きいと硬い系になる | PLECS の FAQ [S11]、IM の説明 [S5] |
| (a2) 電圧ビハインドリアクタンス（VBR。voltage-behind-reactance）、端子のインダクタンス一定 | 固定子の各相を「一定の R と L ＋ 状態で決まる電圧源」の枝で表し、固定子の電流は回路の未知数。回転子の側の状態（磁束）は素子の中の状態方程式 | 任意の回路（ダイオード、開放、デッドタイム）に直結できる。行列が一定のまま（使い回しが崩れない）。誘導機と表面磁石形はこの形で厳密（2.2、2.3） | 突極（IPMSM、同期機）は端子のインダクタンスが角度で変わるので、一定の部分＋電圧源で近似するか、更新が要る | Wang ら [S18]（誘導機の VBR。1ステップ 108 flops、1.6 µs）、[S11]（VBR が既定の勧め）、[S12]（コード生成では一定のインダクタンスの周りに式を組み直し、変わる分を電圧源で模擬）、[S17] |
| (a3) VBR、端子のインダクタンスが時間で変わる | 突極や飽和の分を、端子のインダクタンスの行列の変化として入れる | 突極と飽和が厳密 | 行列が毎ステップ変わる（PLECS も「数値的な効率が下がる」と書く） | [S5]、[S11]、[S12] |

**勧め: (a2) を基本にする。** 誘導機は逆Γ形（2.2）で端子が R_s + R_R、L_σ、e_s = −(α − jω_m)ψ_R になり、表面磁石形 PMSM は R_s、L、e = jω_eψ_m e^{jθ_e} になる。どちらも端子の行列は一定。突極機は (a2) の近似（[S17]、[S12] の組み直し）から始め、精度が足りない場面だけ (a3)。

### 3.2 案 (b) abc の結合インダクタ（回転子の角度で変わる相互インダクタンス）を回路の行列に入れる

固定子3相と回転子3相（かご形は等価な3相）の 6×6 のインダクタンスの行列 L(θ) を E に入れ、v = R·i + d(L(θ)·i)/dt = R·i + L(θ)·di/dt + ω·(dL/dθ)·i の第3項を G に入れる。

- 精度: 相の量のまま解くので、非対称（相の欠け、巻線の短絡）や、巻線関数による空間高調波の拡張まで素直に入る。研究での価値は高い。
- 速度: E と G が毎ステップ変わる。いまの核では `prepare`（行列の用意）を毎ステップ呼ぶことになる。**実測（この文書のため。Linux、Python 3、未知数 14〜38 の RLC の梯子形）で、`prepare` 1回は 0.87〜2.4 ms、1ステップ（P·x + Q·u）は 2.2〜2.8 µs、比は 400〜1000 倍。** 機械の端子だけの低ランク更新にすれば下げられるが、それでも使い回しの設計（D-007）から外れる。
- 決まり2: 配列と数値だけで書けるので反しない。ただし核の最内ループで行列の分解をすることになる。
- 勧め: いまの核では採らない。故障や空間高調波の研究の用途が出たら、別の「多ループ（巻線関数）のモデル」として改めて検討する。**solver-engineer の検討（D-068）で、非線形素子のために毎ステップ組み立て直す解法（ニュートン法、可変刻み）に移るなら、(b) の費用の差は縮むので、そのとき評価し直す。**

### 3.3 案 (c) 等価回路の定常解析

すべりを掃引して、トルク、電流、力率、効率、エアギャップ電力、損失の内訳を複素数の代数で求める（2.2 の式）。

- 精度: 定常の正弦波（基本波）の範囲で厳密。インバータの高調波、過渡は扱わない。
- 速度: 1 点あたり数十の複素数の演算。全すべりの掃引でも一瞬。
- 決まり2: 核を使わない。
- 検証: 恒等式（T_max が R_r によらない、s_maxT の式、P_m = (1 − s)·P_ag）、損失の収支、教科書の数値例（[S1] の Problem 7.12 は T_max ≈ 6.4 N·m、s ≈ 0.0625。回路の値は M1 で原典に当たってから使う）、試験の手順の往復（8.7 の手順で求めた定数で無負荷・拘束の条件を計算し直すと、試験の値に戻る）。
- 教育での価値がいちばん高い（すべり−トルク曲線、L形と T形の差、R_r を変えたときの曲線の動き、二重かご形）。

### 3.4 案 (d) 回転座標の状態平均化モデル（この文書で足した案）

インバータを状態平均化モデル（指令 × 直流電圧）にして、電動機を回転子座標（PMSM）か同期座標（誘導機）で解く。速度一定なら線形時不変で、電流制御の一巡伝達関数を解析的に作れる。決まり6 の「モデルの種類（詳細度）」の「平均」と「理想」（トルク源＋電流応答の一次遅れ）に当たる。ゲインの最適化（E2 と同じ流れ）を回すのはこちら、確かめはスイッチングモデル（(a2)）。

## 4. 解法への要求（solver-engineer へ）

電動機の側から解法に求めること。方式は solver-engineer の検討（`devices-and-solver.md`）で決める。どの方式でも、検証（決まり5、`model-validation`）を付けられること。

| # | 要求 | 理由と目安 |
|---|---|---|
| R-1 | **端子のインダクタンスが回転子の角度で変わる素子**（突極: IPMSM、同期機）を扱う方法を1つ用意する。候補: (i) 一定のインダクタンス＋変わる分を電源で模擬（[S12]、[S17]）、(ii) 機械の端子のブロックだけの低ランク更新、(iii) 毎ステップの組み立て直し（非線形の解法に移るなら） | 行列の作り直しは 1 ステップの 400〜1000 倍（3.2 の実測）。誘導機と表面磁石形は (a2) で角度によらないので、この要求が要るのは突極機だけ |
| R-2 | **素子の内部状態を時間刻みごとに進める口**。核の最内ループの決まり（配列と数値だけ）を守り、素子の種類ごとに「パラメータの配列、状態の配列、端子の未知数の番号」で持つ。速度に比例する係数（誘導機の jω_m·ψ_R、PMSM の逆起電力）を、2次精度とエネルギーの収支を保って扱う。候補: 磁束を回路の未知数に入れて速度の項だけを行列の外の写像で扱う分割法、制御周期ごとの行列の作り直し（3.2 の実測から見積もると、制御周期 2000 ステップごとに作り直すとき、スイッチング状態が1つなら計算時間が 1.2〜1.5 倍、三相インバータの 8 状態なら 2.6〜4.4 倍。1 ステップを P·x + Q·u だけと見た上限の見積もりで、実際の `run_switched` の1ステップはこれより重いので、比は小さくなる）、1 ステップ前の値からの外挿（1次の誤差でノルムが増えうるので、検証が要る） | いまは制御周期でしか外に戻らない（F-5）。逆起電力を制御周期で区分一定にすると、50 Hz、制御周期 100 µs で位相が約 0.9° 遅れる（半周期分の保持。ω·Ts/2 = 2π·50·50e-6 rad）ので足りない |
| R-3 | **磁気飽和**（L_m(|ψ|)、L_d(i_d, i_q)、DC 機の φ(i_f)）。端子のインダクタンスは一定に保ち、非線形は素子の中（数変数のニュートン法）で解くか、区分線形の磁化曲線を「スイッチング状態」と同じ仕組み（区分ごとに行列を用意して使い回す）で扱う。後者は E が区分で変わるので、いまの核の「E は一定」（F-3）を変える必要がある | 自己励磁誘導発電機の電圧、起動の突入電流、弱め界磁は飽和なしでは計算できない（2.2） |
| R-4 | **機械系との連成**。内部の機械系（慣性、粘性摩擦、二慣性）は電気と同じ時間刻みで進める。外部の物理エンジン（D-011）とは、交換の周期（制御周期の整数倍）でトルクを保持して渡し、角度と速度を受け取る。交換の遅れと、エネルギーの食い違い（∫T_e·ω_m dt と機械の側の仕事の差）を結果に出す | 決まり6（トルクを出し、角度と速度を受け取る口）。ばね定数の大きい軸や、ガタのある減速機では、交換の周期が粗いと不安定になりうるので、食い違いを見える形にする |
| R-5 | **長い計算**。電動機の起動は 0.1〜数秒。記録の間引き（信号を選ぶ、k ステップごと）を持つ。状態平均化モデル（インバータの平均）で長い区間を計算し、短い区間だけスイッチングモデルで確かめる流れを持つ | 100 kHz を 200 分割すると 1 秒で上限の 2000 万ステップ（F-8） |
| R-6 | **E1d（インダクタだけの切断集合）**。星形結線で中性点が浮いた固定子は、VBR の RL 枝3つがそのまま切断集合になる | 電動機の前提。E1d が無いと、インバータで駆動する星形の電動機が解けない |
| R-7 | **線形の従属電源**（VCVS、VCCS、CCVS、CCCS）と、それで作るジャイレータ | φ 一定の DC 機と機械系の電気的な類推を、行列のまま書ける（3.6）。D-068 の自由な回路にも要る |
| R-8 | **一定の結合インダクタ**（3×3 まで）。零相の経路がある固定子（中性点を引き出す、Δ結線の循環電流）で、相の間の相互インダクタンスが要る。巻線形の回転子の端子は回転子側の VBR（R-2 の口）で扱う | 電動機に要る範囲はこれだけ。変圧器、LCL の系統連系は V3 の段で、solver-engineer の検討に従う |
| R-9 | **素子の内部の量を信号として出す**（トルク、速度、角度、磁束、すべり、励磁電流）。結果の信号にも、制御器の検出値にも使える。エンコーダとレゾルバの量子化は E1h と同じ考え方で、制御器の側の部品にする | 制御器はいま回路の未知数しか測れない（F-6） |
| R-10 | **定常から始める初期値**。等価回路の定常解（M1）から、磁束、電流、速度、角度の初期値を作って渡す口 | 起動の過渡を毎回計算すると長い（R-5） |
| R-11 | **エネルギーの収支を確かめる量**（入力電力、銅損、鉄損、磁気エネルギーの変化、機械出力）を出す | 検証の段2（保存則） |

## 5. 結合インダクタと変圧器（電動機に要る範囲だけ）

MNA への入れ方の詳細は solver-engineer の文書に譲る。電動機の側から要ることは R-8 のとおりで、次の確認だけ書く。

- 結合インダクタは、各インダクタの枝電流を未知数にし、枝の式に相手の電流の微分の項 M·di/dt を足す（[S20]）。結合係数 K = M/√(L_1·L_2)、範囲は −1〜1（[S20]、LTspice [S21]）。いまの E に非対角の項が入るだけで、一定なら使い回しは崩れない（F-3、F-4）。|K| = 1（漏れゼロ）は行列が特異になるので、理想変圧器として別の素子にするのが普通（理想変圧器は VCVS と CCCS の組で表す。[S22]）。
- 電動機の T形等価回路を相互インダクタンスで書くと、固定子・回転子の結合係数 K = L_m/√(L_s·L_r) < 1 になる。逆Γ形（2.2）は、この結合を漏れ L_σ と回転子の状態に分け直したもので、端子に結合インダクタを置かずに済む。**電動機のために一定の結合インダクタが要るのは、R-8 の零相の場面だけ**。

## 6. 制御で作る「仮想の素子」

### 6.1 「仮想容量」の意味の候補（PO に確かめる）

日本語の資料で「仮想容量」という語そのものは見つからなかった（仮想同期発電機の博士論文 [S24] と技術誌 [S23] を確かめたが、出てくるのは「仮想同期発電機」「疑似慣性」「仮想インピーダンス」）。PO の問いの文脈（誘導機、励磁）に照らして、次の6つが考えられる。

| # | 意味 | どんなものか | このツールでの位置 |
|---|---|---|---|
| A | 制御で作る仮想キャパシタ（virtual capacitor） | 変換器の制御で、ある節点にコンデンサがあるように振る舞わせる（並列）。または出力に直列のコンデンサがあるように振る舞わせる（直流分を除く。Natarajan と Weiss [S27]） | 制御ブロック（6.2） |
| B | 直流リンク・直流マイクログリッドの仮想容量（仮想慣性） | 直流の母線の電圧の変化を、変換器の制御で遅くする（コンデンサ電流の制御による方式 [S28]）。交流の慣性 J と直流のコンデンサ C_dc は対応づけられる（マッチング制御: J_r = C_dc/k_θ²。Tayyebi ら [S26]） | 制御ブロック（6.5） |
| C | 交流系統の疑似慣性（仮想同期発電機、グリッドフォーミング） | 変換器に同期発電機の動揺方程式をまねさせ、慣性と制動を持たせる（[S25]、[S26]、[S23]） | 制御ブロック（6.4） |
| D | 計算の都合で置く架空のコンデンサ・抵抗（架空のスナバ） | 電動機を電流源でつなぐモデル（3.1 の a1）で、端子電圧を決めるために置く。トルクに誤差が出て、値によっては硬い系になる（[S11]、[S5]）。E1d（インダクタの切断集合）を小さなコンデンサで解く方法も同じ種類 | 置かない設計を勧める（(a2) なら要らない）。置くなら、計算の都合の素子として結果に明示する（決まり4） |
| E | 自己励磁誘導発電機の励磁用コンデンサ | 実在のコンデンサ。誘導機の「励磁」と結びつく。電圧の値は磁気飽和で決まる（[S29]） | 回路の素子（C）。誘導機の飽和（R-3、M5）が要る |
| F | 定格容量（kVA）の意味の「容量」 | 単位法の基準容量など | 値の読み取り（8章）の話 |

**PO への問い:** 「仮想容量」は A〜F のどれか（複数か）。とくに、誘導機の文脈で出たのが D（モデルの都合の素子）か E（励磁用コンデンサ）か、制御の文脈の A〜C か。

### 6.2 仮想インピーダンス（virtual impedance）の式とブロック

仮想インピーダンスは、変換器の制御で、実在しない R、L、C が回路にあるように振る舞わせる。目的は、安定化（アクティブダンピング（active damping））、外乱の抑制、指令値の生成による補助的な機能（故障時の運転継続、電力の流れの制御、高調波・不平衡の補償）（Wang ら [S30]）。

| 種類 | 変換器 | 式（素子の式そのもの） | ブロックでの書き方 |
|---|---|---|---|
| 並列の仮想抵抗 | 電流で働く（電流指令を出す） | i_add = −v/R_v | 検出値 v × 定数 |
| 並列の仮想容量 | 同上 | i_add = −C_v·dv/dt | 不完全微分 C_v·s/(1 + s·T_f)。その節点に実在のコンデンサ C があれば、そのコンデンサ電流 i_C（= C·dv/dt）に C_v/C を掛けて作れる（微分しない） |
| 並列の仮想インダクタンス | 同上 | i_add = −(1/L_v)·∫v dt | 積分器（アンチワインドアップつき） |
| 直列の仮想抵抗 | 電圧で働く（電圧指令を出す） | v_add = −R_v·i_o | 検出値 i_o × 定数 |
| 直列の仮想インダクタンス | 同上 | v_add = −L_v·di_o/dt。回転座標では −jω·L_v·i_o の近似も使う | 不完全微分、または dq の交差項。フィルタのインダクタを制御で大きくしたように見せる（[S27] の3番目の改良） |
| 直列の仮想容量 | 同上 | v_add = −(1/C_v)·∫i_o dt | 積分器。系統電流の直流分を除く（[S27] の5番目の改良） |

### 6.3 遅れを含めた等価インピーダンス（LCL フィルタのコンデンサ電流帰還）

LCL フィルタ（インバータ側 L_1、コンデンサ C、系統側 L_2）で、コンデンサ電流 i_C を係数 H_c で電圧指令から引く（仮想抵抗によるアクティブダンピング）。変換器の利得を K_pwm（デューティを指令とするなら直流電圧）、指令から出力までの遅れを e^{−sλT_s} とする。

**導出（この文書）。** 帰還の分がインバータ側のインダクタに作る電流は −K_pwm·H_c·e^{−sλT_s}·i_C/(s·L_1)。i_C = s·C·v_C を入れると −(K_pwm·H_c·C/L_1)·e^{−sλT_s}·v_C で、これはコンデンサの節点に並列のアドミタンス Y_eq = (K_pwm·H_c·C/L_1)·e^{−sλT_s} と同じ。s = jω で

  Z_eq(jω) = R_A·e^{jλωT_s}、 R_A = L_1/(K_pwm·H_c·C)
  並列の等価抵抗 R_eq = R_A/cos(λωT_s)、 並列の等価リアクタンスは誘導性（0 < λωT_s < π のとき）

R_eq は λωT_s > π/2、つまり **f > f_s/(4λ) で負になる**。このツールの決まり（演算遅れ 1 サンプル＋PWM の保持 0.5 サンプル、λ = 1.5）では **f > f_s/6**。これは Pan ら [S31] の結論（遅れのため、比例のコンデンサ電流帰還はコンデンサに並列の仮想インピーダンスと等価になり、共振周波数がサンプリング周波数の 1/6 より上では負性抵抗を含み、一巡伝達関数に不安定な極の組ができる）と一致する。Parker ら [S32] は、遅れを入れた離散時間の解析で、共振の位置により「アクティブダンピングが要らない／どの制御器でも安定にできない／アクティブダンピングが必須」の3つの領域があると示している。

**このツールにとっての意味。** 仮想の素子は、遅れの分だけ設計値と違う素子として働く。だから、(1) 仮想の素子の値を「実際に働く等価インピーダンス」（周波数ごと）として表示し、(2) 負性抵抗の帯域に共振が入るときは注意を出し、(3) 余裕の計算に 1.5 サンプルを必ず入れる（決まり、`basic-design.md` 6.3）。

### 6.4 仮想同期発電機（VSG）、疑似慣性、ドループ

- 同期機の動揺方程式（swing equation）: dθ/dt = ω、J·dω/dt = T_m − T_e − D_f·ω（[S26] の式 (4)）。
- 仮想同期発電機（virtual synchronous machine）: J_r·dω/dt = (p* − p)/ω* + D_p·(ω* − ω)、dθ/dt = ω。換算した慣性定数 H = J_r·ω*/2、制動 D = D_p·ω*（[S26] の式 (13b) と表）。
- ドループ制御（droop control）: ω = ω* + d_ω·(p* − p)。慣性は 0。一定の条件で仮想同期発電機と等価になる（D'Arco と Suul [S25]、[S26]）。
- 電圧の側: 簡単なモデルでは内部誘起電圧と同期インピーダンスで出力電圧の指令を作る V_ac = E_f − Z_s·I_ac（明電舎の VSG-PCS [S23]）。これは直列の仮想インピーダンス（6.2）と同じ形。
- Zhong と Weiss のシンクロンバータ [S33] は、インバータに同期発電機をまねさせ、周波数と電圧のドループで並列の電力分担をする。

### 6.5 直流リンクの仮想容量（仮想慣性）

- マッチング制御: dθ/dt = k_θ·v_dc。直流リンクのコンデンサが慣性の役をし、J_r = C_dc/k_θ²、D_f = G_dc/k_θ²（[S26]）。
- 直流マイクログリッドの仮想慣性: 変換器の出力インピーダンスが慣性の応答を歪めるので、コンデンサ電流の制御で慣性をまねる方式がある（Swaminathan ら [S28]。中身は要旨だけ確かめた）。
- このツールでは、直流の母線の電圧の検出値から、6.2 の並列の仮想容量（または仮想インダクタンスとドループ）の形のブロックで表す。

### 8.7 試験の結果から誘導機の定数を求める手順

出典は [S9]（式の番号は [S9] のもの）。この手順の計算はコードで決定的に行い、AI に計算させない（決まり1）。

1. **直流抵抗**: R_dc = V_dc/I_dc（11）。中性点が使えれば R_1 = R_dc、端子間しか測れなければ（普通）R_1 = R_dc/2（12。Y 結線の端子間）。
2. **無負荷試験**（定格の電圧と周波数、軸は無負荷）: S_nl = 3·V_1,nl·I_1,nl（13）、Q_nl = √(S_nl² − P_nl²)（14）、X_nl = Q_nl/(3·I_1,nl²)（15）。回転子の枝はほぼ開放なので X_nl = X_1 + X_m（16）。
3. **拘束試験**（回転子を止め、低い電圧と、なるべく低い周波数 f_bl で、定格電流まで上げる）: S_bl = 3·V_1,bl·I_1,bl（17）、Q_bl = √(S_bl² − P_bl²)（18）、R_bl = P_bl/(3·I_1,bl²)（19）、X_bl = (f_rated/f_bl)·Q_bl/(3·I_1,bl²)（20）。
4. **X_1 と X_2 の分け方**: NEMA の設計の区分で X_bl を分ける（A: 0.5/0.5、B: 0.4/0.6、C: 0.3/0.7、D: 0.5/0.5。[S9] の表1。巻線形の値は [S9] に無い）。
5. **回転子**: X_2 = (X_bl − X_1)(X_nl − X_1)/(X_nl − X_bl) ≈ X_bl − X_1（21。X_2 ≪ X_m のとき）、R_2 = (R_bl − R_1)·((X_2 + X_m)/X_m)²（22）。X_m = X_nl − X_1。
6. **規格**: IEC 60034-28:2012 は、低圧かご形三相誘導電動機（枠番号 56〜400）の1相の等価回路の要素を求める試験の手順を定める。逆回転試験と拘束試験に加えて、負荷曲線の試験から求める手順を持つ（[S19]。規格の本文は有料で、この文書では範囲だけ確かめた）。

**推測を入れないための注意。** 手順4の分け方は、試験からは決まらない**仮定**（NEMA の区分による慣例）。結果に「X_1 : X_2 = 0.4 : 0.6 と仮定（出典: NEMA 区分 B の慣例、[S9] 表1）」と出し、利用者が認めるまで「仮定」の印を付ける。区分が設計書に無ければ、分け方を選ばずに不足として聞く。鉄損と機械損の分離（無負荷の電力から 3·I²·R_1 を引いた残り）は、電圧を変えた無負荷試験が要る（出典は未確認。M1 で確かめる）。

### 8.8 読み取りで取り違えやすいもの（まとめ）

線間と相、実効値と波高値、電気角と機械角（極対数）、V/krpm と V/(rad/s)、Y と Δ、単位法の基準、温度（抵抗と磁石磁束）、変換の取り方（振幅不変と電力不変）。どれも「約束が書いていない」ときに既定値で埋めない。換算の約束も、値と同じく出典を持つ。

### 9.3 決まり1・3・4 との関係

- **決まり1（AI は抽出と説明だけ）。** 設計書・銘板・試験の記録から AI が取り出すのは、生の値と、その約束（線間か相か、実効値か波高値か）と出典まで。試験の結果から定数を求める計算（8.7）、K_e の換算（8.2）、標準のパラメータからの換算（8.3）は、決定的なコードで行う。
- **決まり3（AI が出すのは層A だけ。D-068 で改める）。** 利用者が回路（層B）を書くのは、AI が書くのとは別の話。電動機の側からの勧め: AI が出すのは「部品のパラメータ（出典つきの値）」までにし、回路のつなぎ方は人が書くか、テンプレート（出発点の例）から選ぶ。AI にネットリストのつなぎ方を書かせるかどうかは、D-068 の (5) と一緒に PO が決める。
- **決まり4（推測で埋めない。未達を達成と表示しない）。** NEMA の区分による X_1・X_2 の分け方（8.7）は仮定として印を付け、利用者が認めるまで残す。換算の約束が書いていない値は、値が読めても不足として聞く。仮想の素子では、遅れで負性抵抗になる帯域を注意に出し、設計した値ではなく実際に働く等価インピーダンスを見せる（6.3）。架空のスナバのような計算の都合の素子は、置くなら結果に明示し、その影響を測って出す。

| 制御ブロック、仮想の素子、グリッドフォーミング | 式は論文。motulator の制御の部品の取り込み（観測器、グリッドフォーミング） | ブロック図の記述と実行、このツールのタイミングの決まり（1 + 0.5 サンプル）への合わせ込み |
| 検証の参照 | SciPy の `solve_ivp` | 参照のための小さな式のモデル（実装と独立に書く） |
| 書き出し | SciPy の `io.savemat`、NumPy | 版の記録（小） |

### 11.3 ライセンスで気づいたこと（release-manager とオーケストレーターへ）

- 電動機と制御の Python のライブラリは、本体が MIT / BSD でも、ほとんどが matplotlib（独自の文面の許諾 [S39]）を実行時の依存に持つ。D-069 の厳しい読み方では、それだけで依存に入れられない。取り込み（MIT・BSD のコードを表示つきで写す）なら使える。
- SciPy の同梱物には Qhull の独自のライセンスと BSL-1.0 がある（[S47]）。D-069 の許可の一覧（MIT、BSD-2/3、Apache-2.0、ISC、PSF、zlib、パブリックドメイン相当）に BSL-1.0 は無い。SciPy はエンジンの中核（LU 分解、零空間）なので、外すのは現実的でない。PO の判断（Q-4）として上げることを勧める。

## 12. この領域（電動機と制御）の、既存のものの割合と自作が要る部分

工数で見積もる（コードと試験と検証の合計。測ったものではなく、この文書の見積もり）。

### 12.1 道1: 自前の回路エンジンに電動機を入れる（D-068 の「自由な回路」と「寄生成分つきの半導体」と同じ回路で電動機を駆動する）

| 部分 | 工数の割合 | そのうち既存のもの |
|---|---|---|
| 電動機の式（モデル） | 15% | 約 7 割（motulator の取り込み、教科書の式） |
| エンジンとの結合（R-1〜R-11、E1d、突極、飽和、機械系の連成、長い計算） | 35% | 0（このエンジン固有） |
| 制御の解析（伝達関数、離散化、周波数応答、余裕） | 10% | 約 6 割（SciPy。余裕の判定は自作の一般化） |
| 最適化 | 10% | 約 3 割（SciPy の探索。評価関数と設計目標は自作） |
| 制御ブロック、仮想の素子、グリッドフォーミング | 10% | 約 3 割（式は論文、一部は motulator から取り込み） |
| 定常解析、試験からの定数、値の換算 | 5% | 約 2 割（NumPy。式は文献） |
| 検証（試験、参照、例） | 15% | 約 1 割（SciPy の solve_ivp。比べる相手は自作） |
| **合計** | 100% | **約 2〜3 割が既存のもの、7〜8 割が自作** |

自作の大半は「このエンジンとの結合」と「検証」。どちらも、自前の回路エンジンを持つことから来る。

### 12.2 道2: 電動機のドライブは式のレベルで計算する（motulator と同じ作り。回路エンジンとは分ける）

電動機・変換器・制御を式で書き、常微分方程式の解法で解く。motulator はこの作りで、誘導機・PMSM・同期リラクタンス、飽和、ダイオード整流、LCL、グリッドフォーミング、離散時間の制御、デッドタイムまで持つ（[S40]）。依存として入れられないので取り込みになるが、取り込んだコードは既存のものとして数えると、**電動機と制御の領域の 6〜7 割が既存のもの、自作は 3〜4 割**（同期機・DC 機の一部、設計目標 → ゲイン → 検証の流れ、このツールのタイミングと量子化の決まり、設計書からの値の換算、検証）。

ただし道2では、半導体の寄生容量（D-068 の (2)）と電動機を同じ回路で見ることはできない（変換器は理想スイッチか平均の式）。

### 12.3 結論（D-069 の (3) への材料）

- **電動機と制御の「式」と「数値の部品」は、既存のものでほぼ足りる。** 差別化にならない。
- **自作が要るのは、(1) 自前の回路エンジンとの結合、(2) 設計目標 → ゲイン → 検証の閉じた流れ（E2）、(3) 設計書からの値の読み取りと換算（推測で埋めない約束つき）、(4) 検証。** このうち (2) と (3) が、このツールの差別化（`requirements.md` 1章）にあたる。motulator も gym-electric-motor も、設計目標からゲインを決めて検証まで閉じる機能と、設計書から値を取る機能は持たない（説明の範囲で確かめた。[S40]、[S43]）。
- **大半が既存のものの組み合わせで済むか: 道2 なら、電動機と制御の領域は「既存のもの（取り込み）6〜7 割＋差別化の部分」で済む。** 道1 では、自前の回路エンジンを持つこと自体が自作の大半を生む。だから、詰め直しの問いは「半導体の寄生成分と電動機を同じ回路で計算すること（D-068 の (2)）が、利用者にとって自作の費用に見合うか」になる（Q-3）。

## 付録A 実測の台本

作業ツリーの外に置いて実行した（リポジトリには入れていない。実行で `circuit_sim/__pycache__/` の `kernel`・`mna` のバイトコードが作り直された。どちらも git の対象外）。

```python
import sys, time
sys.path.insert(0, "/home/claude/circuit-sim")
import numpy as np
from circuit_sim.ir import Netlist, Component, DC
from circuit_sim.mna import build_system
from circuit_sim import kernel

def ladder(n_sec):
    comps = [Component(id="V1", type="V", nodes=("n0", "0"), waveform=DC(value=1.0))]
    for k in range(n_sec):
        a, m, b = f"n{k}", f"m{k}", f"n{k+1}"
        comps += [Component(id=f"R{k}", type="R", nodes=(a, m), value=0.1),
                  Component(id=f"L{k}", type="L", nodes=(m, b), value=1e-3),
                  Component(id=f"C{k}", type="C", nodes=(b, "0"), value=1e-6)]
    comps.append(Component(id="RL", type="R", nodes=(f"n{n_sec}", "0"), value=10.0))
    return Netlist(components=comps)

for n_sec in (4, 8, 12):
    s = build_system(ladder(n_sec))
    n = s.E.shape[0]
    h = 1e-7
    t0 = time.perf_counter(); reps = 20
    for _ in range(reps):
        ops = kernel.prepare(s.E, s.G, s.B, h, backward_euler=True)
    t_prep = (time.perf_counter() - t0) / reps
    x = np.zeros(n); u = np.ones(s.B.shape[1])
    t0 = time.perf_counter(); reps2 = 20000
    for _ in range(reps2):
        x = ops.P @ x + ops.Q @ u
    t_step = (time.perf_counter() - t0) / reps2
    print(f"unknowns={n:3d}  prepare={t_prep*1e3:7.3f} ms  one_step(P@x+Q@u)={t_step*1e6:6.2f} us  ratio={t_prep/t_step:8.0f}")
```
