## D-066 の妥当性

**妥当と判断した**（試験を直した）。

- ζz < 1e-6 は、PID の零点の組の Q が 5e5 を超えるノッチで、部品のばらつき（数%）の前では意味が無い。タイプ III の
  零点は普通 ζz = 0.3〜1、LC の共振を零点で打ち消す設計でも、合わせる先の減衰は負荷・ESR・DCR で 1e-3 以上に
  なる。下限 1e-6 は意味のある値から 3 桁以上下。
- 数値の面: 下の照合で、下限ちょうどでも丸めは余白 1e-6° の 1/108。6回目に誤りが出た ζz ≲ 1e-10 は断られる。
