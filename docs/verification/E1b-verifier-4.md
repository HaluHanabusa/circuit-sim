## 見つけた問題（すべて軽微。利用者に不安定なゲインや未達のゲインが渡る例は無い）

1. **Q ≳ 1e16 で、最良の候補の位相が 360° ずれ、不安定な候補を「満たす」と書き、理由も違う**。再現:
   `buck_voltage_mode_pid(24, 22e-6, 100e-6, 1e17, 100e3)` → crossover_at_search_edge「位相余裕が 55° 以上の区間が、
   …上端（2.5e+04 Hz）まで続く」「位相余裕 256.6°（目標の 55° は満たす）、閉ループの極の半径 1.4635（1 以上で
   不安定）」。参照: 交差 25 kHz で −103.4°（−1 からの角度 103.4°）、半径 1.4635。R = 1e16 では margin_not_reached
   （38.8°、半径 0.990）で、R を大きくしても植物は変わらないので、こちらが正しい。`(12, 4.7e-6, 22e-6, 1e17, 1e6)` は
   R = 1e16 で成功（55°）するのに断る。原因（確かめた）: 植物の極の |z|² − 1 は本当は −Ts/(RC)（det Ad = e^{tr A·Ts}）
   だが、Δ の固有値の丸め（約 1e-17）より小さいので `2·Re x + |x|²` が 0 以上になり、`_Loop._arg_sum` が極を単位円の
   外として偏角を数える（R = 1e17 で +2.1e-17、本当は −1e-18）。無負荷の代わりに 1e18 Ω などを入れると起きる。
   直し方の案: 植物の極は |z|² = e^{−Ts/(RC)} < 1 と分かっているので、内側として数えるか、|z|² − 1 を
   expm1(−Ts/(RC)) で求める。試験は xfail(strict)（4通り）。
2. **半径を小数4桁で書くので「閉ループの極の半径 1.0000（1 未満で安定）」と書く**（1 − 1e-9 < 半径 ≦ 0.99995、
   最良の候補の文だけ）。掃引の 395 通り。再現: `buck_voltage_mode_pid(24, 470e-6, 10e-6, 6, 15e3, zero_ratio=1e-4)`
   （参照の半径 0.99999998616）。1.0000 になるときは桁を増やすのがよい。試験は xfail(strict)。
3. **本文の「取れるのは最大 30.0°」が目標 30° と食い違って読める**（最大 29.998°。最良の候補の部分は直ったが、本文は
   小数1桁のまま）。再現: `buck_voltage_mode_pid(24, 470e-6, 10e-6, 15.793045736999451, 15e3,
   zero_damping=0.1653846153846154, filter_ratio=0.0, phase_margin_deg=30.0)`。
4. **正の値でも倍精度で 0 や非正規数になる引数で、GainDesignError でない例外が出る**: r_load = 5e-324 →
   ZeroDivisionError、np.float32(1e-45) → LinAlgError、np.longdouble('1e-4000') → ZeroDivisionError、10**400（int）→
   OverflowError。前の版は numpy の2つを型で断り、5e-324 と 10**400 は前の版でも同じ。倍精度に直した後で正の有限値かを
   確かめるのがよい。
