## D-065 の範囲の妥当性

**妥当と判断した**（試験を直した）。

- Q = R·√(C/L) ≥ 1e-3: 出力の電圧のリプル比 ΔV/V と、インダクタの電流のリプル比 r = ΔI/I から L と C を
  決めると（コンデンサだけのリプル ΔV = ΔI/(8·f_sw·C)）、Q = r/√(8(1−D)·ΔV/V) になる（自分で導いた）。
  Q < 1e-3 には、ΔV/V = 100%・D → 0 でも r < 0.28% が要る。普通の設計（r = 0.1〜0.5、ΔV/V ≤ 5%）は Q ≥ 0.16、
  極端に寄せても（r = 1%、ΔV/V = 10%）Q ≈ 0.01。ESR でリプルを決めて C を大きくすると Q は上がる側。
  負荷の小信号の抵抗が電池の内部抵抗（数 mΩ）のような場合は 1e-3 に近づくが、それは出力の電圧が負荷に
  決められる場合で、電圧モードで電圧を制御する動作点ではない（電流を制御する）。
- 試験の「実用」の 300 通りのうち Q < 1e-3 の 26 通りは、L 1〜10 H と C 10 pF〜1 nF に 1 mΩ〜0.1 Ω の負荷、
  のような組（√(L/C) = 9.7〜3.5e5 Ω）で、22 通りは f_ctrl/f0 < 10（そもそも共振の上に交差を置けない）。
  降圧コンバータの動作点として意味のある組は無い。個々の値の範囲の直積は実用の回路を表さない。
- 範囲を広げた写し（Q_MIN = 1e-8）で Q = 1e-8〜1e-3 を 800 通り: Q ≥ 1e-6 では丸め 4.3e-11° 以下で誤り 0、
  Q ≤ 1e-7 で余裕の丸め 6.5e-4°、誤り 3（理由と文）。境目 1e-3 は数値の面でも 3 桁の余裕がある。
  D-065 の「Q 1e-5〜1e-4 で 2.9e-6°」は、この版では再現しなかった（記録の数字の根拠は前の版のものと思われる）。
- f_ctrl/f0 ≤ 1e11: 写し（上限 1e14）で 1e10〜1e12 を 500 通り、返したもの 0、誤り 0。範囲の中の掃引で返した
  最大の比は 5.45e9。上限は、どのみち断る設計を invalid_argument で早く断るだけ。
- 断るときの文は外れた組み合わせ（Q、f_ctrl/f0）と現在の値を書く。境目のすぐ外の値の書き方は軽微2。
