## 製品に試験の抜け道が無いこと（D-054、依頼の5）

製品のコード（`circuit_sim/app/`、`frontend/src/`）で、環境変数を読むのは設定の場所（`CIRCUIT_SIM_CONFIG_DIR`、
`XDG_CONFIG_HOME`、`APPDATA`）と端末の言語（`LC_ALL` など）と、標準ライブラリの BROWSER だけ。どれも合言葉や
確かめを外さない（`CIRCUIT_SIM_CONFIG_DIR` は置き場所を変えるだけで、権限の確かめは同じに掛かる）。`create_app`
は合言葉が空なら作らず、合言葉を確かめない形を持たない。画面のコードは URL の引数（location.search）を読まない。
試験のための分岐は見つからなかった。

## 見つけた問題

### 1. 軽微: 言語を切り替えても、読み上げ用の領域（aria-live）に前の言語の文が残る（10.4）

- 内容: 開けなかったお知らせなどを読み上げに伝える領域（`data-testid=announce`、見えない）の文は、出たときの言語で
  作られ、言語を切り替えても作り直されない。English にすると `<html lang="en">` の中に日本語の文が残る。画面には
  見えないが、読み上げで頁を読むと、英語の声で日本語の文が読まれうる。10.4「画面の文字がすべて、その場で切り替わる。
  すでに出ているお知らせも…切り替わる」の趣旨から外れる。
- 再現: 日本語で枠を開き、壊れた JSON（`{`）を開く → announce の文が「bad.json を JSON として読めません（1 行目、
