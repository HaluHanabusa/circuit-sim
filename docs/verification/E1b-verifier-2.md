## 確かめたこと

**ゲインの初期値（`tuning/initial.py`）。** 実装とも実装担当の試験とも別の経路で開ループと閉ループを組んだ
（植物は状態の expm で零次ホールド、P(z) を連立方程式で直接、閉ループは状態 [x, u, I, D, e] の 6×6 の行列の固有値、
位相は主値の差が 3° を超える区間を二分してから unwrap）。基準の回路で、前回の自分の値（505 Hz 104°、1663 Hz +26°、
3584 Hz 55.0°、極 0.9669）と一致。

- 前回の不具合（f_ctrl 20 / 25 / 30 kHz で約 255° と報告して不安定なゲインを返す）: 3つとも `margin_not_reached` で失敗を
  返す。最良の候補の余裕（17.6° / 36.8° / 50.0°）と極の半径（0.988 / 0.976 / 0.980）は自分の計算と一致。
- 掃引 4,896 通り（格子 960、選択肢つき 936、乱数 3,000: L 0.3 µH〜3 mH、C 0.3 µF〜3 mF、R 0.1 Ω〜3 kΩ、f_ctrl 3 kHz〜3 MHz、
  Vin 1〜300 V、目標 20〜89°、零点の比・減衰・フィルタの比）: 返した 1,968 通りはすべて、自分の閉ループで安定（最大 0.99999。
  f_ctrl が LC の共振の 1 万倍の積分の極）、自分の余裕は連続の位相でも −1 からの角度でも目標 − 7e-5° 以上。報告の余裕と
  自分の差は最大 7e-5°、極の半径の相対差 4e-10。
- 失敗 2,928 通りの理由は事実と合う: `margin_not_reached` 2,844（自分の計算でも探索の範囲の最大が目標未満。本文の「最大 X°」も一致）、
  `margin_below_target` 47（自分の最小の余裕が目標未満）、`crossover_at_search_edge` 34（上端でも目標以上）、`negative_gain` 3。
  `unstable` は一度も出ない（余裕の確かめが先に効く）。返した設計を4つ、エンジンの閉ループに入れて落ち着くことも見た。
- 軽微1（下）だけが、最良の候補の内容が事実と違う。

**平均モデルのオン抵抗。** 自分で導いた式: 相補のゲートでは、どちらのスイッチが導通していても出力の経路にオン抵抗が1つ入るので、
周期平均で L·d⟨iL⟩/dt = d·Vin − r_on·⟨iL⟩ − ⟨v_out⟩。参照の平均に r_sw = 1 mΩ を入れて照合した。

| 条件 | 今回 | オン抵抗の無い参照と |
|---|---|---|
| 開ループ D = 0.5（Q = 8.75）、平均と厳密な平均 | 0.011%（見積もり 1.4 mV = 0.012%） | 0.485%。r_on 0.9 / 1.1 / 2 mΩ の参照とは 0.049 / 0.051 / 0.48% |
| 開ループ、エンジンのスイッチングと平均 | 0.065%（実装担当の報告 0.464% → 0.065% のとおり）。厳密な参照どうしでも 0.063%（リプルの効果。オン抵抗の有無によらない） | 0.462% |
| 閉ループ3つ、平均と厳密な平均 | 0.0006〜0.0016% | 0.036% |

**三角波の測定点のずれ。** 周期の頭（オフの区間の中央）では iC = 0 から負に変わるので、コンデンサ電圧の山の頂点。
iC を区分ごとに積分して周期平均との差を取ると、[0, (1−D)T/2] で −(ΔI/C)(1−D)²T²/48、[(1−D)T/2, T/2] で
−(ΔI/C)T²[(1−D)D/16 + D²/24]、合わせて T/2 で割ると  Vref − v̄ = ΔI·T·[(1−D)²/24 + D(1−D)/8 + D²/12] = ΔI·(1+D)/(24·f·C)。
実装担当の式と同じ。D = 0.125〜0.875 で、厳密な参照（量子化なし）と 0.0006〜0.0075 mV、エンジン（T/800）と 0.015 mV 以内。
D = 0.5 の形 ΔV/2 は D = 0.25・0.75 で 1.0 mV ずれるので、一般の式が要る。

**微分を測定値に掛けるPID。** D(s) = −Kd·s/(1+Tf·s)·Y(s) を後退差分で離散化: D_k·(Ts+Tf) − Tf·D_{k−1} = −Kd·(y_k − y_{k−1})、
y_{−1} = y_0。乱数300通りで 3.6e-14。指令値が一定なら偏差に掛ける形と 1e-10 以内（丸め）。段差 Δr では偏差に掛ける形だけが
Kd/(Tf+Ts)·Δr（基準の回路で −0.438）余分に跳ねる。`PidController` は測定値を渡す。テンプレートの既定は偏差に掛ける（仕様どおり）。

**版の推定、精度の注意、stats、文言。** 版の欄が無いとき、control に裸の数値が1つでもあれば 0.1（注意に「版（schema_version）が無く」、
挙げるのは裸の項目だけ）、無ければ 0.2（注意なし）。結果は版 0.2 とビット一致。明示の 0.1 は別の文。`rlc_series` に
fidelity を書くと注意が出る（書かなければ出ない）。stats: 平均モデルの `state_changes` は負荷の段差の1、`command_changes` は
自分で数えた周期の頭の指令の変化の数（993・999）と一致。スイッチングは `command_changes` 0、`state_changes` 1998（= 2 × 999 周期）、
負荷の段差で +1。負荷の段差のエラー文は小さいほうの項目を名指しする（前回の軽微4は直った）。範囲の外と単位の文も自然。

## 見つけた問題

1. 軽微: **`f_cross_max` を f_ctrl/2 以上にすると、最良の候補を不安定なのに「目標を満たす」と書く**。
   再現: `buck_voltage_mode_pid(24, 47e-6, 10e-6, 1000, 20e3, f_cross_max=1e9)` → `margin_not_reached`、最良の候補
   「位相余裕 inf°（目標の 55° は満たす）、閉ループの極の半径 18.5910」。自分の閉ループでも 18.59。
   原因の見立て: 探索の上端が 0.9999·ナイキストに丸められ、候補の交差周波数が確かめの格子の端に重なって見つからず、
   `cross.size == 0` で余裕を inf にする。既定（f_ctrl/4）では起きない。失敗は返すので、利用者に不安定なゲインは渡らない。
   試験は xfail(strict)。
2. 軽微: **画面仕様の付録A.4（`docs/design/screens-v0.1.md`）が、平均モデルのオン抵抗 Rleg を書いていない**。
   743・1636・1771 行と `signal.buck_voltage_mode.i(Vleg).desc`（1828 行）が「Vleg は sw と 0 の間」のまま。実装は
   0 ─ Vleg ─ sw_avg ─ Rleg ─ sw。図に Rleg を出すか、説明に「オン抵抗を直列に含む」と書くかを ux-designer が決める。

## 許容差の根拠（追加した試験）

- 開ループの平均と厳密な平均 0.03%: 台形則の周波数の誤差による位相のずれと減る振れ幅の積の見積もり 1.4 mV の約2.5倍。
  オン抵抗の有無の効果の見積もり 56 mV（0.47%）に対して 0.3% を下限にした。
- 開ループのスイッチングと平均: 厳密な参照どうしの差 ＋ 平均 0.03% ＋ スイッチング 0.05%（前回の根拠）。
- 測定点のずれ: 参照と 0.05 mV（式の省略の見積もり 0.01 mV 以下）、エンジンと 0.3 mV（区別したい2つの式の差 1.0 mV の 1/3）。
- 測定値の微分 1e-12（基準1と同じ）。偏差の形との一致 1e-10（r − y の丸めを Kd/(Tf+Ts) ≦ 1e3 倍して 1e-11 程度）。
- 位相余裕: 報告と自分の差 0.05°、目標 − 1e-3°（自分の交差周波数の解き方の丸め。実測 7e-5°）。
